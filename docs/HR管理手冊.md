# HR 管理手冊

這份文件整合了原本的 `人力資源.md` 與 `人事建檔詳細欄位.md`，作為 HR 模組單一入口。

## 1. 模組範圍

- 組織與部門管理
- 員工主檔
- 出勤與排班
- 請假與加班
- 薪資核算
- 績效與培訓

## 2. 員工主檔欄位

- 基本身分：姓名、員編、證件、聯絡方式
- 組織資訊：部門、職稱、職等、主管
- 薪資資訊：薪資類型、薪資結構、銀行帳號
- 合規資訊：勞保、健保、勞退、扣繳
- 出勤資訊：班別、卡號、特休、補休
- 技能資訊：學歷、證照、經歷、語言
- 附件：證件、證照、合約、轉出單

## 3. 核心流程

### 3.1 到職

- 建立員工主檔
- 指派部門與主管
- 建立薪資與保險設定

### 3.2 出勤與請假

- 打卡
- 請假
- 加班
- 排班

### 3.3 薪資

- 月結
- 加班與獎懲
- 勞健保與勞退
- 薪資單發放

### 3.4 離職

- 離職日期
- 離職原因
- 狀態轉為非在職
