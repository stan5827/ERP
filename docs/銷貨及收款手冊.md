# 銷貨及收款手冊

這份文件整合了原本的 `銷貨及收款循環` 與 `銷貨模組業務人員操作測試手冊`，作為銷售、出貨、發票與收款的單一入口。

## 1. 模組目標

- 讓報價、訂單、出貨、開票、收款資料一致
- 讓業務能快速完成日常操作
- 讓財務能依正確單據完成帳款與帳齡管理

## 2. 核心流程

### 2.1 客戶與產品建檔

- 客戶主檔
- 產品主檔
- 授信與條件設定

### 2.2 報價與訂單

- 報價單
- 銷售訂單
- 折扣、幣別、稅別、交期

### 2.3 出貨與開票

- 出貨單 / 揀料單
- 發票開立
- 批號 / 序號追溯

### 2.4 收款與帳齡

- 收款單
- 沖帳
- 帳齡分析
- 催收與異常追蹤

## 3. 業務操作重點

- 先建客戶再報價
- 報價可轉訂單
- 訂單可連動出貨與庫存
- 開票後由財務做收款核銷

## 4. 測試與驗證

- 可用這份文件作為業務測試流程
- 原本的測試手冊內容已併入各章節
