# 預算規劃 (Budget) 表單功能說明

預算規劃模組負責公司各部門年度預算的編製、追蹤與控制。

## 預算年表單

### 功能說明
建立與管理公司各部門或成本中心的年度預算額度，用於財務控制與績效評估。

### 流程指向
1. 主選單 → 預算規劃
2. 點擊右上方「+ 新增預算年」按鈕
3. 填寫彈出視窗中的預算年表單
4. 點擊「確認」完成新增
5. 若需修改，在預算年列表中點擊「編輯」圖標

### 欄位說明

| 欄位名稱 | 欄位類型 | 必填 | 說明 |
|----------|----------|------|------|
| 預算年度 | Number | Y | 預算所屬的西元年份，如 2026、2027 等，必須為四位數字 |
| 總預算金額 | Number | Y | 本年度分配給此預算單位的總預算金額，必須大於等於0 |
| 已用金額 | Number (只讀) | Y | 截至目前已使用的預算金額，系統自動累計計算 |
| 執行率 | Number (只讀) | Y | 已用金額 ÷ 總預算金額 × 100%，顯示預算使用進度 |
| 預算說明 | Textarea | N | 此預算的用途說明或特殊備註 |

### 特殊功能說明

1. **自動計算功能**
   - 已用金額：系統會根據相關費用發生（如採購付款、薪資發放、費用申請等）自動累計
   - 執行率：自動計算已用金額 ÷ 總預算金額 × 100%
   - 當執行率達到或超過100%時，會顯示警告標示

2. **預算控制**
   - 系統可以設定預算警戒線（如80%、90%），當預算使用率達到警戒線時會發出通知
   - 某些嚴格控制的預算項目可能會在超預算時阻止相關交易

3. **多年度管理**
   - 支援管理多個年度的預算，可同時查看歷史年度與當年度預算
   - 有助於預算編製時參考過去年度的使用情況

### 操作按鈕說明（在預算年列表中）

| 按鈕圖標 | 功能說明 |
|----------|----------|
| 👁️ (眼睛) | 查看預算年度詳情 |
| ✏️ (鉛筆) | 編輯預算年度基本資訊 |
| 📊 | 查看預算使用明細（按月份或費用類型分類） |

### 驗證規則

- 預算年度：必填，必須為四位數字（如 2026）
- 總預算金額：必填，必須大於等於0
- 已用金額：只讀欄位，由系統維護
- 執行率：只讀欄位，自動計算
- 預算說明：選填

### 常見操作流程

#### 編製年度預算
1. 點擊「+ 新增預算年」按鈕
2. 填寫預算年度（如 2026）
3. 填寫總預算金額（依據部門需求與公司資源分配）
4. 選填預算說明（說明此預算的主要用途）
5. 點擊「確認」完成新增

#### 監控預算執行
1. 定期查看預算年列表中的執行率欄位
2. 執行率接近或超過100%時，應檢查預算使用情況
3. 點擊「眼睛」圖標查看詳細的預算使用明細
4. 如需調整預算，可編輯總預算金額（依據公司政策而定）

#### 年末結轉
1. 年度結束時，系統會自動將該年度預算設為歷史狀態
2. 新年度預算編製時，可參考前年度的實際使用情況
3. 未用預算依據公司政策可能轉入下年度或結轉為盈餘
