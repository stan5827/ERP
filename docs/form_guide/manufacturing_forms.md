# 生產製造 (Manufacturing) 表單功能說明

生產製造模組（MES - Manufacturing Execution System）負責管理公司的生產計畫、工單排派、現場報工和產能監控。

## 工單建立表單

### 功能說明
建立生產工單（Work Order），是生產執行的基礎單據，包含產品資訊、數量、排程、BOM、工藝等完整資訊。

### 流程指向
1. 主選單 → 生產製造 · MES
2. 點擊右上方「+ 建立工單」按鈕
3. 填寫彈出視窗中的工單建立表單
4. 點擊「確認」完成新增
5. 工單建立後需經「派工」流程才能開始生產

### 欄位說明

| 欄位名稱 | 欄位類型 | 必填 | 說明 |
|----------|----------|------|------|
| 工單類型 | Select | Y | 一般=正常生產工單、重工=不良品重新加工、樣品=新產品試製、維修=設備或模具維修 |
| 優先度 | Select | Y | 決定排程優先順序，緊急工單將優先佔用產線產能 |
| 產品 | Select | Y | 要生產的成品或半成品料號，系統將自動帶出對應的BOM與製程 |
| BOM 物料清單 | Select | N | 選擇此工單使用的BOM版本。若不選，系統將自動帶出該產品的最新有效BOM |
| 計劃數量 | Number | Y | 預計生產的數量，決定材料用量計算與產能排程。最小為1 |
| 計劃開始日 | Date | Y | 工單預計開始生產的日期，影響產線排程與材料準備 |
| 計劃結束日 | Date | Y | 工單預計完成的日期，須晚於開始日。作為交期承諾與產能評估依據 |
| 製造工藝 | Select | N | 選擇此工單的生產製程工藝路徑，若不選則使用BOM預設工藝 |
| 生產線/工作中心 | Select | Y | 指定此工單在哪條生產線或工作中心執行，影響產能排程與成本計算 |
| 備註 | Textarea | N | 補充說明，如特殊包裝要求、客戶要求等，供現場人員參考 |

### 特殊功能說明

1. **自動帶出功能**
   - 選擇產品後，系統自動帶出該產品的基本資訊
   - 若有多個BOM版本，可手動選擇特定BOM，否則使用最新有效版本
   - 工藝路線會根據選擇的BOM自動帶出預設值

2. **日期驗證**
   - 結束日期必須晚於開始日期
   - 系統會在提交前自動檢查此邏輯

3. **數量限制**
   - 計劃數量必須大於等於1
   - 支援整數輸入（如100片、50組等）

4. **工單類型說明**
   - 一般：正常的生產工單
   - 重工：用於不良品重新加工或維修
   - 樣品：用於新產品試製或客戶樣品製作
   - 維修：用於設備維修或模具保養

### 操作按鈕說明（在工單列表中）

| 按鈕圖標 | 功能說明 | 條件 |
|----------|----------|------|
| 👁️ (眼睛) | 查看工單詳情 | 所有狀態 |
| ✏️ (鉛筆) | 編輯工單 | 待發放、已發放狀態（未開始生產時） |
| 📤 (發送) | 派工 | 已發放狀態，將工單分配給特定工作中心或人員 |
| 📊 | 查看進度詳情 | 生產中、已完工狀態 |
| 📋 | 查看報工記錄 | 所有狀態 |

## 派工表單

### 功能說明
將已建立且狀態為「已發放」的工單分配給特定的工作中心、生產線或作業人員，是工單進入生產執行階段的必要步驟。

### 流程指向
1. 主選單 → 生產製造 · MES
2. 在工單列表中找到狀態為「已發放」的目標工單
3. 點擊操作欄的「派工」圖標（發送圖示）
4. 填寫彈出視窗中的派工表單
5. 點擊「確認派工」完成派工
6. 工單狀態將變更為「生產中」，可開始現場報工

### 欄位說明

| 欄位名稱 | 欄位類型 | 必填 | 說明 |
|----------|----------|------|------|
| 產品 | Text (只讀) | Y | 顯示工單對應的產品名稱 |
| 數量 | Text (只讀) | Y | 顯示工單的計劃生產數量 |
| 派工日期 | Date | Y | 派工執行的日期，預設為今日 |
| 派工人員 | Select | Y | 選擇負責此工單的作業人員或小組 |
| 備註 | Textarea | N | 輸入派工說明，如特殊注意事項、設備準備狀態等 |

### 特殊功能說明

1. **資訊只讀顯示**
   - 派工表單會顯示工單的產品和數量資訊，但不可修改
   - 防止誤派工到錯誤的工單

2. **人員選擇**
   - 派工人員下拉選單會顯示可用的作業人員或小組
   - 通常會顯示人員姓名及所屬組別（如「王小明 - 生產一組」）

3. **狀態自動更新**
   - 派工完成後，系統會自動將工單狀態從「已發放」變更為「生產中」
   - 此時工單即可進入現場報工階段

### 操作流程

#### 派工操作
1. 在工單列表中找到狀態為「已發放」的目標工單
2. 點擊操作欄的「派工」圖標（發送圖示）
3. 在彈出的派工視窗中：
   - 確認顯示的產品和數量是否正確
   - 選擇派工日期（預設為今日）
   - 選擇負責的作業人員或小組
   - 選填備註說明（如有特殊注意事項）
4. 點擊「確認派工」按鈕
5. 系統會顯示成功訊息並關閉視窗
6. 工單列表中該工單的狀態會變更為「生產中」

#### 查看派工詳情
1. 在工單列表中找到目標工單
2. 點擊操作欄的「眼睛」圖標查看工單詳情
3. 在工單詳情頁面中可以查看派工記錄
4. 包括派工時間、派工人員、備註等資訊

## 現場報工表單（簡介）

> 注意：現場報工功能可能透過專用終端機或簡化介面實施，以下為概念說明

### 功能說明
作業人員在生產線上實時回報工單的執行進度，包括完成數量、工時消耗、不良品等資訊。

### 常見報工項目
| 報工項目 | 說明 |
|----------|------|
| 完成數量 | 已生產合格品的數量 |
| 工時消耗 | 實際花費的工時數量 |
| 不良品數量 | 在檢驗中判定為不良品的數量 |
| 報廢數量 | 無法修復且必須報廢的數量 |
| 不良原因 | 不良品發生的具體原因代碼 |
| 設備停機 | 設備故障或調整導致的停機時間 |
| 異常說明 | 生產過程中發生的其他異常情況 |

### 報工流程
1. 作業人員領取派工單或在終端機上查看分配的工單
2. 開始生產作業
3. 在作業進行中或完成後，使用報工介面填報實際執行情況
4. 系統根據報工資料更新工單的實際產量、進度等資訊
5. 可多次報工，直到工單完成所有計劃數量

## 驗證規則

### 工單建立表單
- 工單類型：必填
- 優先度：必填
- 產品：必填
- 計劃數量：必填，必須大於等於1
- 計劃開始日：必填
- 計劃結束日：必填，必須晚於開始日
- 生產線/工作中心：必填
- BOM 物料清單：選填（未選則自動帶出最新有效版本）
- 製造工藝：選填（未選則使用BOM預設工藝）
- 備註：選填

### 派工表單
- 派工日期：必填
- 派工人員：必填
- 產品：只讀顯示（來自工單資料）
- 數量：只讀顯示（來自工單資料）
- 備註：選填

## 常見操作流程

### 完整生產流程
1. **工單建立**：生產計畫部門根據訂單或預測建立工單
2. **工單審核**：主管或排程師審核工單資訊是否正確
3. **工單發放**：工單狀態變更為「已發放」，等待派工
4. **工單派工**：分配給特定工作中心和作業人員，狀態變更為「生產中」
5. **現場報工**：作業人員在生產線上回報執行進度
6. **料領與退料**：領取所需原料，退回未使用料料
7. **品質管制**: 進行程序品檢（IPQC）和終檢（FQC/OQC）
8. **工單完工**：當實際完成數量達到計劃數量時，工單狀態變更為「已完工」
9. **工單結案**: 完成所有後續作業（如檢驗、入庫等）後，工單狀態變更為「已結案」

### 工單狀態說明
| 狀態 | 說明 | 可執行操作 |
|------|------|------------|
| 待發放 | 工單已建立，等待審核和發放 | 編輯、刪除 |
| 已發放 | 工單已核准發放，等待派工 | 編輯、派工、查看 |
| 生產中 | 工單已派工，正在生產執行 | 報工、查看進度、編輯（有限制） |
| 已完工 | 工單已完成所有計劃數量 | 查看詳情、產品入庫、結案 |
| 已結案 | 工單所有後續作業已完成，檔案保存 | 僅可查看詳情 |

### 進度計算方式
- 生產進度 = (實際完成數量 / 計劃數量) × 100%
- 例如：計劃生產1000片，實際完成800片，則進度為80%
- 進度會以百分比形式顯示在工單列表中
- 進度條會根據完成程度顯示不同顏色：
  - 紅色系：進度 < 60% (較慢)
  - 黃色系：進度 60%-99% (正常)
  - 綠色系：進度 = 100% (完成)
