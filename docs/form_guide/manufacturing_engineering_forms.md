# 工藝設計 (Manufacturing Engineering) 表單功能說明

工藝設計模組負責管理生產過程中的工作中心、製程工序和工藝路線配置，是生產排程和成本計算的基礎資料。

## 工作中心管理表單

### 功能說明
定義公司的生產線、工作站或工作中心的基本資訊、產能參數和狀態。

### 流程指向
1. 主選單 → 工藝設計 → 工作中心分頁
2. 點擊右上方「+ 新增資料」按鈕
3. 填寫彈出視窗中的工作中心表單
4. 點擊「建立」完成新增
5. 若需修改，在工作中心列表中點擊目標項目進入編輯模式

### 欄位說明

| 欄位名稱 | 欄位類型 | 必填 | 說明 |
|----------|----------|------|------|
| 工作中心代碼 | Text | Y | 唯一識別碼，如 WC-001、CNC-LINE-1 |
| 工作中心名稱 | Text | Y | 工作中心的完整名稱，如：CNC 加工區、組裝線、焊接站 |
| 產能 | Number | Y | 工作中心的理論產能（單位/小時），必須大於等於0 |
| 效率 (%) | Number | Y | 工作中心的實際效率百分比，範圍0-100，預設100 |
| 啟用此工作中心 | Checkbox | Y | 勾選表示該工作中心可用於工藝路線中，停用後將無法選用 |

### 特殊功能說明

1. **產能與效率說明**
   - 產能：理論上每小時可以處理的產品數量
   - 效率：實際產能佔理論產能的百分比，考慮設備故障、調整時間等因素
   - 實際產能 = 理論產能 × (效率/100)

2. **狀態管理**
   - 啟用狀態的工作中心可在工藝路線中被選用
   - 停用狀態的工作中心將無法被新增到工藝路線，但已使用的路線不會受影響
   - 建議在維護期間暫時停用工作中心

### 操作按鈕說明（在工作中心列表中）

| 按鈕圖標 | 功能說明 |
|----------|----------|
| ✏️ (鉛筆) | 編輯工作中心資訊 |
| 🗑️ (垃圾桶) | 刪除工作中心（僅限未被任何工藝路線引用） |

## 製程工序管理表單

### 功能說明
定義生產過程中的個別工序或作業的時間參數、成本設定和屬性。

### 流程指向
1. 主選單 → 工藝設計 → 製程工序分頁
2. 點擊右上方「+ 新增資料」按鈕
3. 填寫彈出視窗中的製程工序表單
4. 點擊「建立」完成新增
5. 若需修改，在製程工序列表中點擊目標項目進入編輯模式

### 欄位說明

| 欄位名稱 | 欄位類型 | 必填 | 說明 |
|----------|----------|------|------|
| 工序代碼 | Text | Y | 唯一識別碼，如 OP-001、TURNING-01 |
| 工序名稱 | Text | Y | 工序的完整名稱，如：車削加工、銑削、焊接、組裝 |
| Setup 時間 (分) | Number | Y | 每批次或每次換線所需的準備時間（分鐘），必須大於等於0 |
| Run 時間 (分) | Number | Y | 每單位產品的加工處理時間（分鐘），必須大於等於0 |
| 時薪 | Number | Y | 此工序的每小時人力成本，用於成本計算，必須大於等於0 |
| 委外加工 | Checkbox | N | 勾選表示此工序是否委外處理，未勾選則為自製 |
| 啟用此工序 | Checkbox | Y | 勾選表示該工序可用於工藝路線中，停用後將無法選用 |

### 特殊功能說明

1. **時間參數說明**
   - Setup 時間：每批生產開始前的準備時間，如夾具設置、程式載入等
   - Run 時間：每單位產品的實際加工時間，用於計算總工時
   - 單件總工時 = Setup 時間/批量 + Run 時間

2. **成本計算**
   - 工序成本 = (Setup 時間/60 + Run 時間×數量/60) × 時薪
   - 委外工序的時薪通常代表委外費用

3. **狀態管理**
   - 啟用狀態的工序可在工藝路線中被選用
   - 停用狀態的工序將無法被新增到工藝路線，但已使用的路線不會受影響

### 操作按鈕說明（在製程工序列表中）

| 按鈕圖標 | 功能說明 |
|----------|----------|
| ✏️ (鉛筆) | 編輯製程工序資訊 |
| 🗑️ (垃圾桶) | 刪除製程工序（僅限未被任何工藝路線引用） |

## 工藝路線管理表單

### 功能說明
定義產品的完整製造流程，包括工序順序、工作中心分配和等待時間。

### 流程指向
1. 主選單 → 工藝設計 → 工藝路線分頁
2. 點擊右上方「+ 新增資料」按鈕
3. 填寫彈出視窗中的工藝路線表單
4. 點擊「建立」完成新增
5. 若需修改，在工藝路線列表中點擊目標項目進入編輯模式

### 欄位說明

#### 基本資訊
| 欄位名稱 | 欄位類型 | 必填 | 說明 |
|----------|----------|------|------|
| 路線代碼 | Text | Y | 唯一識別碼，如 RT-001、MOTOR-ASSY |
| 路線名稱 | Text | Y | 工藝路線的完整名稱，如：馬達組裝路線、殼體加工路線 |
| 產品編號 | Select | Y | 此工藝路線適用的產品料號（關聯SKU） |
| 產品名稱 | Text (只讀) | Y | 自動帶出選擇產品的名稱 |
| 版本 | Text | Y | 工藝路線版本號，如 1.0、1.1、2.0 等 |
| 啟用此工藝路線 | Checkbox | Y | 勾選表示該路線可用於生產訂單，停用後將無法選用 |

#### 工序配置（動態列表）
| 欄位名稱 | 欄位類型 | 必填 | 說明 |
|----------|----------|------|------|
| 工序 | Select | Y | 選擇此路線包含的製程工序（關聯製程工序表） |
| 工作中心 | Select | Y | 選擇執行此工序的工作中心（關聯工作中心表） |
| 轉移 (分) | Number | Y | 從前一工序完成到此工序開始的等待時間（分鐘），必須大於等於0 |
| 等待 (分) | Number | Y | 此工序完成到下一工序開始的等待時間（分鐘），必須大於等於0 |

### 特殊功能說明

1. **自動帶出功能**
   - 選擇產品編號後，系統自動帶出對應的產品名稱
   - 選擇工序後，系統自動帶出對應的工序名稱
   - 選擇工作中心後，系統自動帶出對應的工作中心名稱

2. **工序管理**
   - 支援多工序配置，可按需添加或移除工序
   - 工序順序按照添加順序排序，可透過重新添加來調整順序
   - 每個工序都需要指定工作中心和時間參數

3. **時間參數計算**
   - 單件總處理時間 = Σ(Setup 時間/批量 + Run 時間 + 轉移時間 + 等待時間)
   - 其中Setup時間會均攤到每件產品上（假設批量生產）

4. **狀態管理**
   - 啟用狀態的工藝路線可在建立工單時被選用
   - 停用狀態的工藝路線將無法被新工單選用，但已使用的工單不會受影響
   - 建議在版本更新時先停用舊版本，再啟用新版本

### 操作按鈕說明（在工藝路線列表中）

| 按鈕圖標 | 功能說明 |
|----------|----------|
| ✏️ (鉛筆) | 編輯工藝路線（包括工序配置） |
| 🗑️ (垃圾桶) | 刪除工藝路線（僅限未被任何工單引用） |
| ➕ (加號) | 在工序配置中添加新工序項目 |
| 🗑️ (小垃圾桶) | 刪除工序配置中的特定工序項目 |

## 驗證規則

- 工作中心名稱：必填
- 產能：必填，必須大於等於0
- 效率 (%)：必填，必須在0-100範圍內
- 啟用此工作中心：必填

### 製程工序表單
- 工序代碼：必填
- 工序名稱：必填
- Setup 時間 (分)：必填，必須大於等於0
- Run 時間 (分)：必填，必須大於等於0
- 時薪：必填，必須大於等於0
- 委外加工：選填
- 啟用此工序：必填

### 工藝路線表單
- 路線代碼：必填
- 路線名稱：必填
- 產品編號：必填
- 版本：必填
- 啟用此工藝路線：必填

- 工作中心：每個工序項目必填
- 轉移 (分)：每個工序項目必填，必須大於等於0
- 等待 (分)：每個工序項目必填，必須大於等於0

## 常見操作流程

### 建立新工藝路線
1. 點擊「+ 新增資料」按鈕
2. 在基本資訊區塊填寫：
   - 路線代碼（如 RT-002）
   - 路線名稱（如 泵浦組裝路線）
   - 選擇產品編號（自動帶出產品名稱）
   - 填寫版本號（如 1.0）
   - 勾選「啟用此工藝路線」
3. 在工序配置區塊：
   - 點擊「添加工序」按鈕添加第一個工序
   - 選擇工序（如 OP-001 車削加工）
   - 選擇工作中心（如 WC-001 CNC 加工區）
   - 填寫轉移時間（如 5 分鐘）
   - 填寫等待時間（如 3 分鐘）
   - 重複以上步驟添加所有所需工序
   - 如需調整工序順序，可刪除後重新添加
4. 點擊「建立」完成新增

### 工藝路線版本管理
1. 當需要修改現有工藝路線時，建議建立新版本而非直接修改
2. 步驟：
   - 找到目標工藝路線
   - 點擊「編輯」進入編輯模式
   - 修改版本號（如從 1.0 變更為 1.1）
   - 根據需要修改工序配置
   - 點擊「更新」完成修改
   - 新版本將可在建立工單時選用
   - 舊版本可保留供歷史參考或選擇性停用

### 在生產工單中的應用
1. 建立工單時，在「製造工藝」欄位中選擇對應的工藝路線
2. 系統會自動帶出該路線的所有工序配置
3. 工單的排程和成本計算將基於這個工藝路線進行
