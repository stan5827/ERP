# 人力資源 (HR) 表單功能說明

人力資源模組包含員工資料管理、出勤管理、請假審批和薪資核算四大功能區塊。

## 員工資料表單

### 功能說明
管理員工的個人資料、工作經歷、薪資資訊和法定保障等完整人事檔案。

### 流程指向
1. 主選單 → 人力資源 → 員工資料分頁
2. 點擊右上方「+ 新增員工」按鈕
3. 填寫彈出視窗中的員工資料表單
4. 點擊「確認」完成新增
5. 若需修改，在員工列表中點擊「編輯」圖標

### 欄位說明

#### 身分資料分頁
| 欄位名稱 | 欄位類型 | 必填 | 說明 |
|----------|----------|------|------|
| 中文姓名 | Text | Y | 員工的中文姓名，必須與身分證件相符 |
| 英文姓名 | Text | N | 護照上的英文姓名 |
| 身分證字號 | Text | Y | 格式：1個大寫英文字母+9位數字（如 A123456789） |
| 護照號碼 | Text | N | 外籍員工必填 |
| 出生日期 | Date | Y | 用於年資計算與勞基法適用判定 |
| 性別 | Select (M/F) | Y | 性別資料 |
| 手機號碼 | Text | Y | 格式：09開頭的10位數字（如 0912345678） |
| 市話號碼 | Text | N | 住家或辦公室電話 |
| 電子郵件 | Text | N | 必須包含 @ 符號 |
| 戶籍地址 | Text | Y | 同身分證登記地址 |
| 通訊地址 | Text | N | 實際收件地址 |

#### 緊急聯絡分頁
| 欄位名稱 | 欄位類型 | 必填 | 說明 |
|----------|----------|------|------|

#### 組織職位分頁

|----------|----------|------|------|
| 所屬部門 | Select | Y | 員工所屬的行政部門 |
| 職稱 | Select | Y | 正式任用後的職稱 |
| 職等 | Select | Y | 薪資職等(如P1-P6或 Grade A-F) |

### 特殊功能說明

1. **員工離職處理**
   - 在員工列表中找到目標員工（僅限在職員工）
   - 點擊操作欄的「X」圖標（離職按鈕）
   - 填寫離職日期（必填）和離職原因（選填）
   - 點擊「確認」完成離職處理
   - 離職後員工狀態將變更為「離職」，並停止系統權限

2. **出勤管理**
   - 人力資源 → 出勤管理分頁
   - 點擊「+ 新增出勤」按鈕新增出勤記錄
   - 可核准待審核的出勤記錄（點擊「✓」圖標）

3. **請假審批**
   - 人力資源 → 請假審批分頁
   - 點擊「+ 新增請假」按鈕新增請假申請
   - 主管可核准或退回待審核的請假（點擊「✓」或「✗」圖標）

4. **薪資核算**
   - 人力資源 → 薪資核算分頁
   - 選擇薪資年月（月份選擇器）
   - 點擊「+ 新增薪資」按鈕新增薪資記錄
   - 主管可核准草稿狀態的薪資（點擊「✓」圖標）

## 驗證規則

- 身分證字號：必須符合 `/^[A-Z]\d{9}$/` 格式
- 電子郵件：必須包含 @ 符號
- 手機號碼：必須符合 `/^09\d{8}$/` 格式
- 底薪：不可為負數
- 試用期截止日：必須晚於到職日
- 必填欄位：未填寫時會顯示紅色邊框和提示訊息
