# 採購及付款 (Procurement) 表單功能說明

採購及付款模組涵蓋採購訂單管理、內部請購單處理、供應商管理等功能。

## 採購訂單 (PO) 表單

### 功能說明
建立與管理對外供應商的採購訂單，從詢價到到貨驗收的完整流程。

### 流程指向
1. 主選單 → 採購及付款 → 採購單列表分頁
2. 點擊右上方「+ 新增採購單」按鈕
3. 填寫彈出視窗中的採購訂單表單
4. 點擊「確認」完成新增
5. 若需修改，在採購單列表中點擊「編輯」圖標

### 欄位說明

#### 基本資訊
| 欄位名稱 | 欄位類型 | 必填 | 說明 |
|----------|----------|------|------|
| 供應商 | Select | Y | 選擇發放此採購單的供應商對象 |
| 採購日期 | Date | Y | 採購單據的開立建檔日期 |
| 付款條件 | Text | N | 與供應商議定的應付帳款結帳期限 |
| 貿易條件 | Select (EXW/FOB/CIF/DDP) | N | 國際貿易術語(Incoterms) |
| 幣別 | Select (TWD/USD/JPY/EUR/CNY) | Y | 決定此採購單收貨與請款時的計算基準貨幣 |
| 匯率 | Number | Y | 外幣兌換本地貨幣(TWD)的匯率（TWD則填1） |
| 稅碼 | Select (TX1/TX0/TX2) | Y | 稅務類型代碼：應稅5%/免稅/零稅率 |
| 預計交貨日 | Date | Y | 供應商承諾將貨品送達的日期 |
| 收貨倉庫 | Select | Y | 指定此採購單的收貨入庫倉庫 |

#### 採購明細項目
| 欄位名稱 | 欄位類型 | 必填 | 說明 |
|----------|----------|------|------|
| 品號 / 品名 | Select | Y | 選擇採購的產品（自動帶出單位、單價等資訊） |
| 採購數量 | Number | Y | 必須大於0，支援小數 |
| 單位 | Text (只讀) | Y | 根據選擇的品號自動帶出 |
| 單價 | Number | Y | 單價金額，必須大於等於0 |
| 轉換率 | Number | Y | 採購單位到庫存單位的轉換比例（預設1） |
| 庫存單位 | Text (只讀) | Y | 根據選擇的品號自動帶出 |
| 小計 | Number (只讀) | Y | 系統自動計算：數量 × 單價 |

### 特殊功能說明

1. **自動帶出功能**
   - 選擇品號後，系統自動帶出對應的單位、標準單價
   - 庫存單位和轉換率也會自動計算

2. **小計自動計算**
   - 修改數量或單價後，小計會即時更新
   - 底部顯示所有明細的未稅總金額

3. **從請購單拋轉**
   - 當從請購單列表點擊「拋轉採購」時，會自動帶出請購單的明細項目
   - 需要選擇供應商、付款條件等採購單特有欄位

4. **鎖定功能**
   - 採購單確認後可以進行鎖定，防止誤修改
   - 鎖定後需要管理員權限才能解除
   - 鎖定狀態會在列表中顯示鎖定圖標

### 操作按鈕說明（在採購單列表中）

| 按鈕圖標 | 功能說明 | 條件 |
|----------|----------|------|
| 👁️ (眼睛) | 查看採購單明細 | 所有狀態 |
| ✏️ (鉛筆) | 編輯採購單 | 未鎖定狀態 |
| 🔒/🔓 (鎖定/解鎖) | 鎖定或解鎖採購單 | 已確認狀態 |
| ✅ (勾選) | 確認訂單 | 待確認狀態 |
| ➡️ (右箭頭) | 產生進貨單/收貨單 | 已確認或部分到貨狀態 |

## 內部請購單 (PR) 表單

### 功能說明
內部部門發起的採購需求申請，經主管核准後可拋轉為正式採購單。

### 流程指向
1. 主選單 → 採購及付款 → 請購單列表分頁
2. 點擊右上方「+ 新增內部請購單」按鈕
3. 填寫彈出視窗中的請購單表單
4. 點擊「確認」完成新增
5. 待主管核准後，可點擊「拋轉採購」生成採購單

### 欄位說明

#### 基本資訊
| 欄位名稱 | 欄位類型 | 必填 | 說明 |
|----------|----------|------|------|
| 申請部門 | Select | Y | 發起此採購需求的內部單位 |
| 專案代號 | Text | N | 如: PROJ-2023-01，用於專案成本分析 |
| 請購原因 | Textarea | Y | 說明為何需要此採購（庫存不足、生產需求等） |

#### 請購明細項目
| 欄位名稱 | 欄位類型 | 必填 | 說明 |
|----------|----------|------|------|
| 品號 / 品名 | Select | Y | 選擇需求的產品（自動帶出單位） |
| 需求數量 | Number | Y | 必須大於0，支援小數 |
| 單位 | Text (只讀) | Y | 根據選擇的品號自動帶出 |
| 需求日期 | Date | Y | 需要將貨品送達的日期 |
| 預估單價 | Number | Y | 參考價格，系統將自動帶出標準成本 |
| 小計 | Number (只讀) | Y | 系統自動計算：數量 × 預估單價 |

### 特殊功能說明

1. **自動帶出功能**
   - 選擇品號後，系統自動帶出對應的單位和預估單價（標準成本）

2. **小計自動計算**
   - 修改需求數量或預估單價後，小計會即時更新
   - 底部顯示所有明細的未稅總金額

3. **鎖定功能**
   - 請購單經主管核准後可以進行鎖定，防止修改
   - 僅未鎖定的請購單可以拋轉為採購單

### 操作按鈕說明（在請購單列表中）

| 按鈕圖標 | 功能說明 | 條件 |
|----------|----------|------|
| 👁️ (眼睛) | 查看請購單明細 | 所有狀態 |
| ✅ (勾選) | 主管審核（核准） | 待審核狀態 |
| ❌ (X) | 主管審核（退回） | 待審核狀態 |
| 🔒/🔓 (鎖定/解鎖) | 鎖定或解鎖請購單 | 已核准狀態 |
| ➡️ (右箭頭) | 拋轉採購單 | 已核准且已鎖定狀態 |

## 供應商管理表單

### 功能說明
建立與管理供應商資料，包括基本資訊、聯絡方式、付款條件和評等等。

### 流程指向
1. 主選單 → 採購及付款 → 供應商列表分頁
2. 點擊右上方「+ 新增供應商」按鈕
3. 填寫彈出視窗中的供應商資料表單
4. 點擊「確認」完成新增
5. 若需修改，在供應商列表中點擊「編輯」圖標

### 欄位說明

#### 基本資訊
| 欄位名稱 | 欄位類型 | 必填 | 說明 |
|----------|----------|------|------|
| 供應商代號 | Text | Y | 唯一識別碼，如 SUP-001 |
| 供應商名稱 | Text | Y | 供應商全名 |
| 統一編號 | Text | N | 8位數公司統一編號 |
| 聯絡人 | Text | N | 主要聯絡人姓名 |
| 電話/手機 | Text | N | 聯絡電話號碼 |
| Email | Text | N | 電子郵件地址 |
| 付款條件 | Text | N | 與供應商議定的付款方式 |
| 評等 | Text | N | 供應商評等（A/B/C等級） |
| 發票地址 | Text | N | 寄送發票的地址 |
| 交貨地址 | Text | N | 貨品送達的地址 |
| 狀態 | Select (active/inactive) | Y | 啟用或停用狀態 |

### 特殊功能說明

1. **供應商評核**
   - 在供應商列表中點擊「 clipboard 」圖標可查看供應商評核詳細資訊
   - 包括品質、交期、價格三項評分及歷史記錄

2. **狀態管理**
   - 可隨時將供應商設為「啟用」或「停用」狀態
   - 停用的供應商不會在採購單的供應商選項中出現

## 驗證規則

### 採購訂單表單
- 供應商：必填
- 採購日期：必填
- 幣別：必填
- 匯率：必填，預設值為1.0
- 稅碼：必填
- 預計交貨日：必填
- 收貨倉庫：必填
- 採購數量：必須大於0
- 單價：必須大於等於0

### 內部請購單表單
- 申請部門：必填
- 請購原因：必填
- 品號 / 品名：必填
- 需求數量：必須大於0
- 單位：自動帶出（只讀）
- 需求日期：必填
- 預估單價：必填

### 供應商表單
- 供應商代號：必填
- 供應商名稱：必填
- 狀態：必填
