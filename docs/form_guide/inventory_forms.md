# 庫存管理 (Inventory) 表單功能說明

庫存管理模組負責公司所有物料和產品的進銷存管理，包括SKU維護、庫存異動、倉庫管理等。

## SKU主檔表單

### 功能說明
建立與管理庫存單位（Stock Keeping Unit）的基本資訊，是所有庫存作業的基礎。

### 流程指向
1. 主選單 → 庫存管理
2. 預設顯示SKU管理分頁
3. 點擊右上方「+ 新增SKU」按鈕
4. 填寫彈出視窗中的SKU表單
5. 點擊「確認」完成新增
6. 若需修改，在SKU列表中點擊「編輯」圖標

### 欄位說明

| 欄位名稱 | 欄位類型 | 必填 | 說明 |
|----------|----------|------|------|
| 品項代碼 (SKU號碼) | Text | Y | 唯一識別碼，如 ITEM-001 或 MATERIAL-A001 |
| 品項名稱 | Text | Y | 品項的完整名稱 |
| 規格型號 | Text | N | 規格描述，如尺寸、顏色、版本等 |
| 單位 | Select (PCS/KG/L/SET/etc.) | Y | 存放單位，如片(PCS)、公斤(KG)、公升(L)、套(SET) |
| 類別 | Text | N | 物料分類，如原料、半製成品、成品、包裝材料等 |
| 安全庫存水位 | Number | Y | 最低補貨點，當庫存低於此量時觸發補貨警告 |
| 最高庫存量 | Number | N | 最大庫存限制，防止過度庫存 |
| 當前庫存量 | Number (只讀) | Y | 現有庫存數量，系統自動維護 |
| 庫別 | Select | Y | 所屬倉庫，如 主倉庫、次倉庫、寄售倉庫等 |
| 儲位 | Text | N | 倉庫內的具體位置，如 A-01-05 |
| 補貨點 (ROP) | Number | N | 自動補貨觸發點，低於此量時建議採購量 |
| 前置時間 | Number | N | 採購前置天數，從下單到到貨所需時間 |
| 標準成本 | Number | N | 標準單位成本，用於成本計算 |
| 狀態 | Select (active/inactive) | Y | 啟用或停用狀態，停用的SKU不會參與交易 |

### 特殊功能說明

1. **庫存自動維護**
   - 當有採購到貨、生產領料、製品入庫、銷售出庫等作業時，系統自動更新當前庫存量
   - 庫存變動會產生庫存異動記錄，可追蹤

2. **安全庫存警告**
   - 當庫存量低於安全庫存水位時，在列表中會顯示警告標記
   - 可設定自動通知負責人進行補貨

3. **多倉庫管理**
   - 支援多個倉庫，每個SKU可以在不同倉庫有不同的庫存量
   - 需要指定庫別才能進行庫存作業

### 操作按鈕說明（在SKU列表中）

| 按鈕圖標 | 功能說明 |
|----------|----------|
| 👁️ (眼睛) | 查看SKU詳情 |
| ✏️ (鉛筆) | 編輯SKU基本資訊 |
| 📊 | 查看庫存異動歷史 |
| 📦 | 查看各倉庫庫存分布 |
| 🔄 | 調整庫存（盤點盈虧） |

## 倉庫管理表單

### 功能說明
建立與管理公司的倉庫資訊，包括倉庫基本資訊、負責人和聯絡方式。

### 流程指向
1. 主選單 → 庫存管理 → 倉庫管理分頁（或透過SKU編輯時選擇庫別）
2. 點擊「+ 新增倉庫」按鈕
3. 填寫彈出視窗中的倉庫表單
4. 點擊「確認」完成新增

### 欄位說明

| 欄位名稱 | 欄位類型 | 必填 | 說明 |
|----------|----------|------|------|
| 倉庫代號 | Text | Y | 唯一識別碼，如 WH-001、MAIN、SUB |
| 倉庫名稱 | Text | Y | 倉庫的完整名稱 |
| 負責人 | Text | Y | 倉庫管理負責人姓名 |
| 聯絡電話 | Text | N | 倉庫聯絡電話 |
| 地址 | Textarea | N | 倉庫詳細地址 |
| 儲位格式 | Text | N | 倉庫儲位編碼規則，如 {區域}-{排}-{層}-{位} |
| 負責成本中心 | Select | N | 倉庫費用歸屬的成本中心 |
| 狀態 | Select (active/inactive) | Y | 倉庫是否啟用使用 |

## 庫存調整表單（盤點盈虧）

### 功能說明
進行實際盤點時，將實際庫存量與系統庫存量進行比較並調整差異。

### 流程指向
1. 主選單 → 庫存管理 → SKU列表
2. 在目標SKU上點擊「調整庫存」按鈕
3. 填寫彈出視窗中的庫存調整表單
4. 點擊「確認」完成調整

### 欄位說明

| 欄位名稱 | 欄位類型 | 必填 | 說明 |
|----------|----------|------|------|
| 調整前庫存量 | Number (只讀) | Y | 系統目前記錄的庫存量 |
| 調整後庫存量 | Number | Y | 實際盤點後的庫存量，必須大於等於0 |
| 調整原因 | Select (盤點盈餘/盤點虧損/損壞報廢/其他) | Y | 調整發生的原因 |
| 調整說明 | Textarea | N | 詳細的調整原因說明或備註 |
| 調整日期 | Date | Y | 調整發生的日期，預設為今日 |

### 特殊功能說明

1. **自動計算差異**
   - 系統會自動計算調整後庫存量 - 調整前庫存量 = 調整數量
   - 正數表示盈餘，負數表示虧損

2. **庫存異動記錄**
   - 每次庫存調整會產生一筆庫存異動記錄
   - 異動類型會根據調整原因自動設定（如盤點盈餘、盤點虧損等）

3. **成本影響**
   - 庫存調整會影響相關的成本計算
   - 盈餘會增加庫存資產，虧損會增加費用或減少資產

### 驗證規則

#### SKU主檔表單
- 品項代碼：必填
- 品項名稱：必填
- 單位：必填
- 安全庫存水位：必填，必須大於等於0
- 最高庫存量：如果填寫，必須大於等於安全庫存水位
- 當前庫存量：只讀欄位，由系統維護
- 庫別：必填
- 儲位：選填
- 補貨點：如果填寫，必須大於等於0
- 前置時間：如果填寫，必須大於等於0
- 標準成本：如果填寫，必須大於等於0
- 狀態：必填

#### 倉庫管理表單
- 倉庫代號：必填
- 倉庫名稱：必填
- 負責人：必填
- 聯絡電話：選填
- 地址：選填
- 儲位格式：選填
- 負責成本中心：選填
- 狀態：必填

#### 庫存調整表單
- 調整前庫存量：只讀
- 調整後庫存量：必填，必須大於等於0
- 調整原因：必填
- 調整說明：選填
- 調整日期：必填

### 常見操作流程

#### 新增SKU
1. 點擊「+ 新增SKU」按鈕
2. 填寫品項代碼、品項名稱、單位（必填）
3. 選填規格型號、類別
4. 填寫安全庫存水位（必須大於等於0）
5. 選填最高庫存量（如果填寫，必須大於等於安全庫存水位）
6. 選擇庫別（必填）
7. 選填儲位
8. 選填補貨點、前置時間、標準成本（如果填寫，必須大於等於0）
9. 選擇狀態（必填）
10. 點擊「確認」完成新增

#### 庫盤點流程
1. 列印或匯出當前SKU清單作為盤點單
2. 實際進行倉庫盤點，記錄實際庫存量
3. 在系統中對每個SKU點擊「調整庫存」按鈕
4. 填寫調整後庫存量（實際盤點量）
5. 選擇調整原因（通常為盤點盈餘或盤點虧損）
6. 填寫調整說明（如實際盤點過程中的特別情況）
7. 選擇調整日期（通常為盤點日期）
8. 點擊「確認」完成調整
9. 系統會自動生成庫存異動記錄並更新財務相關數據

#### 日常庫存作業
- 採購到貨：系統自動增加對應SKU的庫存量
- 生產領料：系統自動減少對應原料SKU的庫存量
- 製品入庫：系統自動增加對應成品SKU的庫存量
- 銷售出庫：系統自動減少對應成品SKU的庫存量
- 所有作業都會產生庫存異動記錄，可追蹤
