# 固定資產 (Assets) 表單功能說明

固定資產模組負責公司固定資產的全生命週期管理，從採購、折舊、維護到報廢。

## 固定資產表單

### 功能說明
管理固定資產的基本資訊、財務資訊、位置資訊和狀態變更。

### 流程指向
1. 主選單 → 固定資產
2. 點擊右上方「+ 新增資產」按鈕
3. 填寫彈出視窗中的固定資產表單
4. 點擊「確認」完成新增
5. 若需修改，在資產列表中點擊「編輯」圖標（鉛筆圖示）

### 欄位說明

| 欄位名稱 | 欄位類型 | 必填 | 說明 |
|----------|----------|------|------|
| 資產編號 | Text | Y | 固定資產的唯一識別碼，如 ASSET-001 |
| 資產名稱 | Text | Y | 固定資產的完整名稱，如：CNC 加工中心機、辦公室隔間、空調設備等 |
| 規格型號 | Text | N | 資產的型號、規格或料號，有助於後續維護與採購參考 |
| 資產類別 | Text | N | 資產所屬的類別 |
| 存放位置 | Text | N | 資產的存放位置或使用部門 |
| 取得成本 | Number | Y | 資產的取得成本（含稅），作為折舊計算與資產帳面價值的基準，必須大於0 |
| 取得日期 | Date | Y | 資產開始使用的日期，決定折舊提列的起始期間 |
| 耐用年限 | Number | Y | 資產預估可使用的年數，用於計算每月折舊金額（平均法），必須大於等於1 |

### 特殊功能說明

1. **折舊自動計算**
   - 系統會根據取得成本、耐用年限自動計算月折舊額
   - 月折舊 = 取得成本 ÷ (耐用年限 × 12)
   - 累計折舊 = 月折舊 × 已使用月數
   - 帳面價值 = 取得成本 - 累計折舊

2. **資產狀態管理**
   - 資產狀態包括：使用中、閒置、維護中、已報廢
   - 狀態變更會影響折舊計算（閒置及維護中期間可能暫停折舊）
   - 已報廢資產不會再計算折舊

3. **位置追蹤**
   - 可記錄資產的存放位置或使用部門
   - 方便進行盤點與維護管理

### 操作按鈕說明（在資產列表中）

| 按鈕圖標 | 功能說明 |
|----------|----------|
| 👁️ (眼睛) | 查看資產詳情 |
| ✏️ (鉛筆) | 編輯資產基本資訊 |
| 📊 | 查看折舊明細（若有實作） |
| 📋 | 查看維護記錄（若有實作） |

### 驗證規則

- 資產編號：必填
- 資產名稱：必填
- 取得成本：必須大於0
- 取得日期：必填
- 耐用年限：必須大於等於1

### 常見操作流程

#### 新增固定資產
1. 點擊「+ 新增資產」按鈕
2. 填寫資產編號、資產名稱（必填）
3. 選填規格型號、資產類別、存放位置
4. 填寫取得成本（必須大於0）
5. 選擇取得日期
6. 填寫耐用年限（必須大於等於1）
7. 點擊「確認」完成新增

#### 編輯固定資產
1. 在資產列表中找到目標資產
2. 點擊「編輯」圖標（鉛筆圖示）
3. 修改需要變更的欄位
4. 點擊「確認」儲存變更

#### 資產狀態變更
1. 在資產列表中找到目標資產
2. 根據實際狀態變更資產狀態欄位
   - 使用中 → 閒置：資產暫時未使用
   - 使用中/閒置 → 維護中：資產正在維修
   - 任何狀態 → 已報廢：資產報廢處理
3. 狀態變更會自動影響折舊計算邏輯
