## 表單操作通用流程

### 1. 新增資料
- 點擊頁面右上方的「+ 新增」按鈕
- 填寫彈出視窗中的表單欄位
- 必填欄位標記為「*」
- 點擊「確認」或「提交」按鈕完成新增

### 2. 編輯資料
- 在資料列表中找到目標記錄
- 點擊操作欄的「編輯」圖標（鉛筆圖示）
- 修改表單欄位
- 點擊「確認」或「更新」按鈕儲存變更

### 3. 查看詳情
- 在資料列表中找到目標記錄
- 點擊操作欄的「查看」圖標（眼睛圖示）
- 瀏覽顯示的詳細資訊
- 點擊「關閉」或「X」返回列表

### 4. 刪除資料
- 在資料列表中找到目標記錄
- 點擊操作欄的「刪除」圖標（垃圾桶圖示）
- 確認刪除操作
- 注意：某些關鍵資料可能無法直接刪除，需要先停用或轉移

### 5. 搜尋與篩選
- 使用頁面上方的搜尋框輸入關鍵字
- 使用篩選條件下拉選單選擇特定狀態或類別
- 按下Enter鍵或點擊搜尋按鈕執行搜尋

### 6. 匯出資料
- 點擊頁面右上方的「匯出」按鈕
- 選擇匯出格式（通常為Excel或CSV）
- 資料將根據當前篩選條件匯出

## 欄位類型說明

| 欄位類型 | 說明 | 輸入方式 |
|----------|------|----------|
| Text (文字) | 單行文字輸入 | 輸入框 |
| Textarea (多行文字) | 多行文字輸入 | 輸入區域 |
| Number (數字) | 數值輸入 | 數字輸入框 |
| Date (日期) | 日期選擇 | 日期選擇器 |
| Select (下拉選單) | 預設選項選擇 | 下拉選單 |
| Checkbox (核取方塊) | 是/否選項 | 勾選框 |
| Radio Button (單選按鈕) | 單選選項 | 單選按鈕群 |

## 必填欄位標記

- 必填欄位會在欄位名稱後顯示「*”符號
- 系統會在提交前自動檢查必填欄位是否已填寫
- 未填寫的必填欄位會顯示紅色邊框或提示訊息

## 驗證規則

表單可能包含以下驗證規則：
- 格式驗證（如電子郵件、電話號碼）
- 範圍驗證（如數值最小/最大值）
- 相依驗證（如某個欄位填值時其他欄位變為必填）
- 邏輯驗證（如結束日期必須大於開始日期）
