# 庫存管理總手冊

這份文件整合了原本的 `庫存管理循環`、`庫存管理執行流程` 與 `庫別說明`，作為庫存模組的單一入口。

## 1. 模組目標

庫存管理的核心是維持正確的帳實一致、可追溯的異動紀錄，以及足夠但不過量的庫存水位。

## 2. 核心主檔

- `SKU` 主檔
- 倉庫主檔
- 儲位主檔
- 批號 / 序號主檔
- 庫別與庫存分類

## 3. 核心流程

### 3.1 入庫

- 採購進貨、完工入庫、退料回庫、補料入庫
- 進貨後可觸發批號、儲位與效期設定

### 3.2 出庫

- 工單領料、銷貨出貨、委外發料、調撥出庫
- 所有出庫都應寫入 `InventoryTransaction`

### 3.3 盤點

- 定期盤點
- 差異比對
- 盈虧調整與原因碼記錄

### 3.4 補貨

- 安全庫存
- 再訂購點 `ROP`
- 需求預測
- 自動請購或自動轉移

## 4. 進階能力

- 批號與效期管理
- FIFO / FEFO
- AS/RS 與 AGV 對接
- AI 盤點與影像辨識
- 自動補貨與動態水位調整
