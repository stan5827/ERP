# 採購及供應商協作手冊

這份文件整合了原本的 `採購及付款循環` 與 `供應商協作平台_需求文件`，作為採購、進貨、付款與供應商入口的單一入口。

## 1. 模組目標

- 確保物料供應準時且可控
- 讓供應商可線上協作報價、確認訂單、出貨與請款
- 建立 PO -> ASN -> GR -> AP 的完整鏈路

## 2. 核心角色

- 採購人員
- 倉管 / 品檢人員
- 財務 AP
- 供應商管理者
- 供應商窗口

## 3. 內部流程

### 3.1 請購 PR

- 需求部門提出請購
- 連動預算、成本中心或工單
- 作為後續 RFQ / PO 的來源

### 3.2 詢比議價 RFQ

- 向多家供應商詢價
- 比對單價、交期、MOQ、品質條件
- 保留評分與決策依據

### 3.3 採購單 PO

- 與供應商確認正式採購條件
- 記錄版本變更、交期、付款條件、附件

### 3.4 進貨 ASN / GR

- 供應商建立出貨通知 ASN
- 倉庫收貨後產生 GR
- 品檢結果與批號、效期一併保存

### 3.5 應付 AP

- 以 PO / GR / Invoice 做三方勾稽
- 自動判斷付款條件與付款狀態
- 保留折讓、扣款與品質異常連動資訊

## 4. 供應商入口

### 4.1 核心功能

- 登入與主檔管理
- RFQ 回覆
- PO 確認 / 拒絕 / 修改請求
- ASN 建立
- 發票與請款
- CAPA / 8D 回覆
- 文件與合約下載

### 4.2 建議權限切分

- 管理者
- 報價窗口
- 出貨窗口
- 財務窗口

## 5. 核心資料

- 請購單
- 詢價單
- 採購單
- 出貨通知 ASN
- 收貨單 GR
- 應付帳款 AP
- 供應商主檔
- 供應商使用者
- 品質客訴與 CAPA
