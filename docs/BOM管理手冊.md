# BOM 管理手冊

這份文件整合了原本的 `BOM.md` 與 `BOM操作手冊.md`，作為 BOM 與工程變更的單一入口。

## 1. BOM 的角色

BOM 是製造業的數據核心，直接影響工單、領料、補料、委外、MRP 與成本捲算。

## 2. 核心資料

- 母件 / 子件
- 用量、損耗率、報廢率
- 版本號、生效日、失效日
- 虛擬件標記、替代料標記
- 低階碼 `LLC`

## 3. 主要流程

### 3.1 建立與維護

- 建立新 BOM
- 新增項目
- Excel 匯入
- 複製 BOM

### 3.2 版本與變更

- ECR 工程變更申請
- ECN 工程變更通知
- BOM 差異比對
- 批次工程變更

### 3.3 下游連動

- 工單展開
- 領料與退料
- 補料與超耗
- 委外撥料
- MRP 展開
- 標準成本捲算

## 4. 常見防呆

- 遞迴循環檢查
- 停用料號檢核
- 生效/失效日期檢核
- 替代料與虛擬件規則

## 5. 建議 API 群組

- `/api/boms`
- `/api/ecrs`
- `/api/ecns`
- `/api/mrp`
- `/api/costing`
