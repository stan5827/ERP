## 1. 系統概述

BOM（Bill of Materials，物料清單）是製造業的數據核心，定義產品的組成結構與用量關係。

### 1.1 BOM 基本架構

```
成品 (Level 0)
├─ 原料 A (Level 1)
├─ 原料 B (Level 1)
└─ 半成品 C (Level 1)
    ├─ 原料 D (Level 2)
    └─ 原料 E (Level 2)
```

### 1.2 BOM 版本狀態

| 狀態 | 說明 | 可操作 |
|------|------|--------|
| 草稿 (Draft) | 建立中，未生效 | 編輯、刪除、發布 |
| 已啟用 (Active) | 生效中，可正常使用 | 建立工單、參考 |
| 已停用 (Deprecated) | 失效，僅供歷史查詢 | 僅供參考 |

## 2. 四大維度操作

### 2.1 工程維度 (Engineering)

#### 2.1.1 建立新 BOM

**路徑**：製造循環 > BOM 管理 > 新建 BOM

**步驟**：
1. 點擊「新建 BOM」按鈕
2. 選擇「母件」（成品料號）
3. 輸入版本號（例如：1.0）
4. 設定生效日期
5. 點擊「儲存」完成建立

**欄位說明**：
| 欄位 | 說明 | 必填 |
|------|------|------|
| 母件 | 要建立 BOM 的成品料號 | ✅ |
| 版本 | BOM 版本號（如 1.0, 2.0） | ✅ |
| 生效日期 | BOM 開始生效日期 | ✅ |
| 失效日期 | BOM 失效日期（可選） | |
| 備註 | BOM 說明 | |

#### 2.1.2 新增 BOM 項目

1. 在 BOM 編輯頁面，點擊「新增項目」
2. 選擇子件料號
3. 輸入用量、單位
4. 設定損耗率、報廢率
5. 儲存

**損耗率與報廢率**：
- **損耗率**：生產過程中的標準損耗（如：5% = 1.05 倍）
- **報廢率**：無法使用的不良品比率（如：2%）

#### 2.1.3 ECR（工程變更申請）

**用途**：在修改 BOM 前發起評估申請

**建立 ECR**：
1. 製造循環 > 工程變更 > 新建 ECR
2. 填寫變更標題、說明、原因
3. 設定優先級（低/中/高/急件）
4. 選擇目標 BOM
5. 提交審核

**ECR 狀態流程**：
```
草稿 → 已提交 → 審核中 → 已核准 → 已關閉
           ↓
       已駁回
```

#### 2.1.4 ECN（工程變更通知）

**用途**：ECR 核准後，正式發布 BOM 變更

**建立 ECN**：
1. 在核准的 ECR 上點擊「生成 ECN」
2. 系統自動填寫變更內容
3. 設定生效日期
4. 發布 ECN，通知相關部門

**ECN 觸發動作**：
- 舊 BOM 版本自動停用
- 新 BOM 版本生效
- 觸發物料庫存檢查

### 2.2 生產執行維度

#### 2.2.1 建立生產工單

**路徑**：製造循環 > 生產工單 > 新建工單

**步驟**：
1. 選擇產品（成品）
2. **選擇 BOM 版本**（新增功能）
3. 輸入預計數量
4. 設定開始/結束日期
5. 點擊「建立工單」

**BOM 版本選擇邏輯**：
- 系統自動顯示該產品的所有生效 BOM 版本
- 可選擇特定版本（預設選第一個 active 版本）
- 工單建立後會鎖定該 BOM 版本

#### 2.2.2 領料單（Material Requisition）

**建立流程**：
1. 工單建立後，系統根據 BOM 自動計算需求
2. 進入「領料單」頁面
3. 確認物料清單
4. 執行領料

**領料邏輯**：
```
工單預計用量 × (1 + 損耗率) = 領料數量
```

#### 2.2.3 退料單（Material Return）

**使用場景**：生產剩餘或發生不良

**操作步驟**：
1. 選擇工單
2. 勾選要退回的物料
3. 輸入退回數量
4. 填寫退回原因
5. 確認退回

#### 2.2.4 補料單（Material Supplement）

**使用場景**：生產過程損耗超出標準

**操作步驟**：
1. 系統自動計算超耗量
2. 生成補料建議
3. 確認補料數量
4. 執行補料

**超耗計算**：
```
實際用量 - (BOM 標準用量 × (1 + 損耗率)) = 超耗量
```

### 2.3 MRP 維度

#### 2.3.1 MRP 建議表

**路徑**：製造循環 > MRP 物料需求計劃

**功能**：
- 根據訂單需求 + BOM 結構計算物料需求
- 產生採購建議

**MRP 執行**：
1. 點擊「執行 MRP」按鈕
2. 系統計算所有物料需求
3. 查看 MRP 建議結果

**MRP 建議欄位**：
| 欄位 | 說明 |
|------|------|
| 料號 | 物料編號 |
| 需求量 | 系統計算的需求總數 |
| 建議採購量 | 考慮庫存後的建議採購數 |
| 需求日期 | 預計需求時間 |

#### 2.3.2 採購請購單

**路徑**：採購 > 請購單

**建立流程**：
1. 從 MRP 建議中選取項目
2. 點擊「生成請購單」
3. 系統自動填寫建議採購量
4. 調整採購數量、單價
5. 提交審核

#### 2.3.3 委外加工單

**用途**：BOM 中定義為委外製作的半成品

**建立流程**：
1. 系統自動識別委外項目
2. 建立委外加工單
3. 自動生成撥料清單
4. 發送給加工商

### 2.4 成本維度

#### 2.4.1 標準成本捲算 (Cost Roll-up)

**路徑**：製造循環 > BOM 管理 > 標準成本計算

**操作步驟**：
1. 選擇要計算的產品
2. 設定計算數量
3. 點擊「開始計算」
4. 查看成本結果

**成本構成**：
```
材料成本 = Σ (子件單價 × 用量 × (1 + 損耗率))
人工成本 = 工序工時 × 人工费率
製造費用 = 工序工時 × 製造费率
總成本 = 材料成本 + 人工成本 + 製造費用
```

**成本結果顯示**：
| 成本項目 | 金額 |
|----------|------|
| 材料成本 | $1,200 |
| 人工成本 | $300 |
| 製造費用 | $200 |
| **總成本** | **$1,700** |

#### 2.4.2 差異分析報表

**路徑**：製造循環 > 成本差異分析

**操作步驟**：
1. 選擇工單
2. 點擊「開始分析」
3. 系統比對 BOM 標準用量與實際領料
4. 查看差異結果

**差異分析欄位**：
| 欄位 | 說明 |
|------|------|
| 料號 | 物料編號 |
| BOM 標準用量 | BOM 定義的理論用量 |
| 實際領料量 | 實際領取的數量 |
| 差異量 | 實際 - 標準 |
| 差異率 | 差異比例 |

## 3. 輔助工具

### 3.1 BOM 複製功能

**用途**：快速建立相似產品的 BOM

**操作步驟**：
1. 進入 BOM 管理頁面
2. 選取要複製的 BOM
3. 點擊「複製 BOM」
4. 選擇新產品料號
5. 調整差異項目
6. 儲存新 BOM

**複製內容**：
- ✅ BOM 項目（子件清單）
- ✅ 用量、損耗率
- ❌ 版本號（需重新輸入）

### 3.2 批次替換

**用途**：批量替換多個 BOM 中的共用零件

**操作步驟**：
1. 進入「批次替換」功能
2. 選擇要替換的舊料號
3. 選擇新料號
4. 系統顯示會影響的 BOM 清單
5. 選取要替換的 BOM
6. 預覽替換結果
7. 執行替換

**替換規則**：
- 保持用量比例不變
- 保留損耗率設定
- 自動更新生效日期

### 3.3 Excel 批次導入

**用途**：快速導入大量 BOM 資料

**操作步驟**：
1. 下載 Excel 模板
2. 填寫 BOM 資料
3. 上傳 Excel 檔案
4. 預覽導入結果
5. 確認導入

**Excel 模板欄位**：
| 欄位名稱 | 說明 | 必填 |
|----------|------|------|
| 母件料號 | 成品編號 | ✅ |
| 版本 | BOM 版本 | ✅ |
| 子件料號 | 原料/半成品編號 | ✅ |
| 用量 | 標準用量 | ✅ |
| 損耗率 | 生產損耗率 | |
| 報廢率 | 不良品比率 | |
| 備註 | 說明 | |

**導入驗證**：
- ✅ 料號是否存在
- ✅ 單位是否匹配
- ✅ 用量是否合理
- ❌ 無效料號會顯示錯誤

### 3.4 CAD/EDA 集成

**用途**：從設計軟體直接導入 BOM

**支援格式**：
- SolidWorks (BOM 表)
- AutoCAD (明細表)
- 其他 CAD 軟體 (CSV/TXT/XML)

**操作步驟**：
1. 從 CAD 軟體導出物料表
2. 進入「CAD BOM 導入」功能
3. 上傳檔案
4. 系統自動解析
5. 預覽結果
6. 確認導入

**對應關係**：
```
CAD 欄位 → ERP 欄位
零件編號 → 子件料號
數量 → 用量
說明 → 備註
```

## 4. 智慧防錯機制

### 4.1 遞迴循環檢查

**功能**：防止 BOM 結構出現循環引用

**檢查邏輯**：
```
如果 (母件 = 子件) 或 (母件是子件的後代)
→ 錯誤：循環引用
```

**系統處理**：
- 儲存 BOM 時自動檢查
- 發現循環引用時阻止儲存
- 顯示錯誤訊息

**常見錯誤**：
```
錯誤：BOM 結構包含循環引用
說明：A 是 B 的母件，B 又是 A 的子件
```

### 4.2 低階碼自動運算 (Low Level Code)

**功能**：計算物料在 BOM 結構中的最低層級

**運算邏輯**：
- 成品：Level 0
- 直接子件：Level 1
- 孫件：Level 2
- ...

**MRP 運算順序**：
```
1. 由低階碼 0 開始（成品）
2. 依序計算低階碼 1, 2, 3...
3. 確保上層需求先彙總
4. 再計算下層需求
```

**系統操作**：
1. 儲存 BOM 時自動計算
2. 可手動觸發「重新計算低階碼」
3. 結果回填至 SKU 主檔

### 4.3 工程生命週期檢核

**功能**：確保 BOM 使用的子件處於可用狀態

**檢核規則**：
| 子件狀態 | 是否可用 | 說明 |
|----------|----------|------|
| 啟用中 | ✅ | 正常使用 |
| 設計中 | ❌ | 未完成，不可發布 |
| 停用 | ❌ | 已停用，建議更換 |
| 作廢 | ❌ | 已作廢，不可使用 |

**操作流程**：
1. 建立或編輯 BOM 時
2. 系統自動檢核子件狀態
3. 若子件不可用，顯示警告
4. 可選擇忽略或替換子件

## 5. 版本管理

### 5.1 BOM 差異比對

**用途**：比較兩個 BOM 版本的差異

**操作步驟**：
1. 進入「BOM 差異比對」功能
2. 選擇基準版本（A）
3. 選擇比較版本（B）
4. 點擊「開始比對」

**視覺化設計**：
| 狀態 | 顏色 | 說明 |
|------|------|------|
| 新增 | 🟢 綠色 | B 版本新增的物料 |
| 刪除 | 🔴 紅色 | A 版本有，B 版本刪除 |
| 變更 | 🟡 黃色 | 用量或損耗率變動 |

**比對結果顯示**：
```
新增 (綠色)：
- SKU-2001: 新增原料，用量 5 個

變更 (黃色)：
- SKU-2002: 用量 2 → 3，損耗率 5% → 8%

刪除 (紅色)：
- SKU-2003: 已移除此組件
```

### 5.2 批次工程變更 (Mass ECN)

**用途**：當共用零件停產時，批量更新所有相關 BOM

**操作步驟**：
1. 系統識別使用停產零件的所有 BOM
2. 顯示 BOM 清單
3. 勾選要更新的 BOM
4. 設定新零件資訊
5. 批次生成 ECN
6. 一次核准所有變更

**適用場景**：
- 供應商停產某零件
- 零件規格升級
- 品質問題替換

### 5.3 BOM 版本歷史

**功能**：追蹤 BOM 變更記錄

**查看方式**：
1. 選取 BOM
2. 點擊「版本歷史」
3. 查看所有版本變更記錄

**歷史記錄內容**：
- 變更類型（建立/更新/複製/啟用/停用）
- 變更說明
- 變更時間
- 變更人員

## 6. 效能優化

### 6.1 Redis 快取策略

**快取 key 設計**：
```
BOM:TREE:{Product_No}:{Version}
BOM:ITEMS:{BOM_ID}
SKU:INFO:{SKU_ID}
```

**快取內容**：
- BOM 樹狀結構
- BOM 項目清單
- SKU 基本資訊

**快取 TTL**：
| 項目 | 快取時間 | 說明 |
|------|----------|------|
| BOM 樹狀 | 24 小時 | 一般讀取頻率較低 |
| BOM 項目 | 1 小時 | 變更頻率較高 |
| SKU 資訊 | 12 小時 | 變更頻率中等 |

### 6.2 快取清除策略

**自動清除**：
- BOM 建立/更新時
- ECR/EVN 執行時
- 工單改製時

**手動清除**：
1. 進入「系統設定 > 快取管理」
2. 選擇清除範圍
3. 執行清除

**清除範圍**：
- 清除特定 SKU 的 BOM 快取
- 清除所有 BOM 快取

### 6.3 快取預熱 (Cache Warming)

**功能**：預先計算常用 BOM 的樹狀結構

**預熱時機**：
- 每日凌晨 2:00
- MRP 執行前
- 手動觸發

**預熱流程**：
1. 系統識別常用成品（查詢頻率高）
2. 預先計算 BOM 樹狀結構
3. 存入 Redis 快取
4. 提升白天讀取速度

**預熱效果**：
- 讀取速度：從 100ms+ 降至 <10ms
- 資料庫壓力：降低 70%

## 7. 工單改製管理

### 7.1 工單改製場景

| 場景 | 複雜度 | 處理方式 |
|------|--------|----------|
| 尚未領料 | 低 | 直接修改 BOM 明細 |
| 已領料未生產 | 中 | 退料 + 補領 |
| 已報工半成品 | 高 | 拆解 + 報廢處理 |

### 7.2 改製操作流程

**步驟 1：啟動改製**
1. 選擇要改製的工單
2. 點擊「工單改製」按鈕
3. 系統自動鎖定工單（防止同時操作）

**步驟 2：差異分析**
```
原始 BOM          改製後 BOM          差異
---------         -----------         -----
A x 10           A x 8              -2 (退料)
B x 5            B x 10             +5 (補領)
                 C x 12             +12 (新增)
```

**步驟 3：處置建議**
| 物料 | 狀態 | 建議動作 |
|------|------|----------|
| SKU-A | 刪除 | 退料 2 個 |
| SKU-B | 變更 | 補領 5 個 |
| SKU-C | 新增 | 發料 12 個 |

**步驟 4：執行改製**
1. 勾選處置方式（退庫/報廢/轉用）
2. 填寫改製原因
3. 確認改製損失
4. 提交審核

### 7.3 改製損失處理

**損失分類**：
- **退料**：退回倉庫，不產生損失
- **報廢**：無法使用，計入成本
- **轉用**：轉給其他工單使用

**成本核算公式**：
```
工單總成本 = (實際領料 - 實際退料) + 報廢物料成本 + 已發生加工費
```

**過帳邏輯**：
```
┌─────────────────┐
│ 改製審核通過    │
└────────┬────────┘
         ↓
┌─────────────────┐
│ 報廢單          │ → 扣減 WIP 價值
└────────┬────────┘
         ↓
┌─────────────────┐
│ 拆解入庫單      │ → 退回可重用物料
└────────┬────────┘
         ↓
┌─────────────────┐
│ 更新工單狀態    │ → 標記「已改製」
└─────────────────┘
```

### 7.4 防呆機制

**限制條件**：
1. **領料不准改**：已投入製程的物料不可改製
2. **庫存檢查**：改製後庫存不足會顯示警告
3. **審核流程**：重要改製需多人審核

**錯誤訊息示例**：
```
警告：SKU-2001 已投入製程，無法改製
建議：工單報廢後重新開立
```

| 問題 | 原因 | 解決方法 |
|------|------|----------|
| BOM 無法儲存 | 有循環引用 | 檢查母件/子件關係 |
| 無法建立工單 | 無生效 BOM | 先建立並啟用 BOM |
| MRP 無結果 | 無訂單需求 | 先建立銷售訂單 |
| 成本計算錯誤 | 無物料單價 | 維護物料成本主檔 |

### 8.3 系統建議

1. **定期維護**：每週檢查 BOM 資料正確性
2. **版本管理**：重要變更前建立備份版本
3. **權限管理**：限制 BOM 修改權限，避免誤刪
4. **備份機制**：定期匯出 BOM 資料備份
