## 四、主要模組執行流程

### 4.1 銷貨模組 (Sales)

```
銷售訂單建立流程：
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  Sales 頁面  │────▶│ FormModal   │────▶│ 儲存 API    │
│             │     │ (表單彈窗)   │     │ (POST)      │
└─────────────┘     └─────────────┘     └─────────────┘
      │                                         │
      │ 取得訂單列表                            │
      ▼                                         ▼
┌─────────────┐                         ┌─────────────┐
│ salesApi.    │                         │ 後端建立    │
│ list()       │                         │ SalesOrders │
└─────────────┘                         └─────────────┘
```

**功能流程**:
1. 顯示訂單列表 (GET /api/sales-orders)
2. 建立新訂單 → FormModal → POST /api/sales-orders
3. 編輯訂單 → PUT /api/sales-orders/{id}
4. 狀態更新 → PATCH /api/sales-orders/{id}/status

## 六、常用功能流程

### 6.1 新增資料流程

```
使用者點擊「新增」按鈕
        │
        ▼
開啟 FormModal 彈窗
        │
        ▼
填寫表單欄位
        │
        ▼
點擊「儲存」按鈕
        │
        ▼
呼叫 useMutation (POST API)
        │
        ├─ 成功 → 關閉彈窗 → 重新整理列表
        │
        └─ 失敗 → 顯示錯誤訊息
```

### 6.2 編輯資料流程

```
使用者點擊資料列「編輯」
        │
        ▼
取得該筆資料 (GET by ID)
        │
        ▼
開啟 FormModal (預填資料)
        │
        ▼
修改欄位
        │
        ▼
點擊「儲存」 (PUT API)
        │
        ├─ 成功 → 更新列表
        └─ 失敗 → 顯示錯誤
```

### 6.3 刪除/狀態更新流程

```
使用者點擊「刪除」/「狀態按鈕」
        │
        ▼
顯示 ConfirmDialog 確認
        │
        ▼
確認後 → 呼叫 API (DELETE/PATCH)
        │
        ├─ 成功 → 更新列表
        └─ 失敗 → 顯示錯誤
```

```
      │
      ▼
┌─────────────────┐
│   axios攔截器   │
│ (response.interceptor)
└────────┬────────┘
         │
    ┌────┴────┐
    ▼         ▼
 成功      錯誤
    │         │
    │         ▼
    │    handleApiError()
    │         │
    │    ┌────┴────┐
    │    ▼         ▼
    │  401     其他錯誤
    │    │         │
    │    ▼         ▼
    │ 清除Token  顯示錯誤
    │ 登入頁     訊息
    │
    ▼
回傳資料給元件
```
