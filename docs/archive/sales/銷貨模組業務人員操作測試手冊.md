# 銷貨模組業務人員操作測試手冊

## 一、系統登入與模組進入

### 1.1 登入系統
1. 開啟瀏覽器，輸入網址：`http://localhost:5173`
2. 輸入帳號密碼登入 ERP 系統
3. 進入系統後，點擊左側選單「銷貨及收款循環 (Sales & Receivables)」

### 1.2 銷貨模組三大功能頁籤
| 頁籤名稱 | 功能說明 |
|---------|---------|
| 報價與訂單 (Sales Order & CRM) | 客戶建檔、產品建檔、報價單、銷售訂單 |
| 出貨與開票 (Fulfillment & Invoice) | 出貨單管理、發票開立 |
| 帳款與收款 (Receivables & Collection) | 帳齡分析、收款紀錄、沖帳管理 |

## 二、客戶建檔 (CRM)

### 2.1 操作目的
建立潛在或現有客戶的基本資料，以便後續報價、訂單、出貨及帳款管理。

### 2.2 操作步驟
1. 進入「銷貨及收款循環」頁面
2. 點擊右上角按鈕：「**客戶建檔**」
3. 彈出「新增客戶資料」視窗，填寫以下欄位：

#### 核心基本欄位（必填）
| 欄位名稱 | 說明 | 範例 |
|---------|------|------|
| 客戶代號 | 唯一識別碼，不可重複 | CUST-001 |
| 客戶全名 | 公司完整名稱 | 台北貿易股份有限公司 |
| 客戶簡稱 | 方便快速辨識 | 台北貿易 |

#### 統一編號
| 欄位名稱 | 說明 | 範例 |
|---------|------|------|
| 統一編號 | 公司統一編號（8碼） | 12345678 |

#### 聯絡資訊
| 欄位名稱 | 說明 | 範例 |
|---------|------|------|
| 主聯絡人 | 負責人員姓名 | 王小明 |
| 職稱 | 聯絡人職位 | 採購經理 |
| 電話 | 公司電話 | 02-12345678 |
| 手機 | 行動電話 | 0912345678 |
| E-mail | 電子郵件 | wang@example.com |

#### 財務與交易欄位
| 欄位名稱 | 說明 | 範例 |
|---------|------|------|
| 固定折扣 | 1.0 = 不打折，0.9 = 9折 | 0.95 |
| 結帳日 | 帳款結算日 | 每月25日 |
| 收款日 | 實際收款日 | 次月10日 |
| 發票通知方式 | Email / 手機簡訊 / 不通知 | email |

4. 填寫完畢後，點擊「**存檔**」按鈕
5. 系統顯示客戶已建立，自動更新客戶列表

### 2.3 測試案例
```
測試案例 1：建立新客戶
- 客戶代號：CUST-TEST01
- 客戶全名：測試貿易有限公司
- 統一編號：87654321
- 主聯絡人：測試人員
- 固定折扣：0.9（9折）
- 預期結果：客戶建立成功，顯示於客戶總覽列表
```

## 四、報價單管理 (Quote)

### 4.1 操作目的
針對潛在客戶或現有客戶進行產品報價，報價單可轉換為正式銷售訂單。

### 4.2 操作步驟
1. 點擊右上角按鈕：「**新增報價單**」
2. 彈出「新增報價單」視窗

#### 選擇客戶
- 從下拉選單選擇已建立的客戶

#### 報價明細
- 點擊「**新增品項**」按鈕
- 選擇產品（系統自動帶入單價）
- 填寫數量
- 系統自動計算小計

#### 折扣設定
- 調整「折扣率」（1.0 = 無折扣，0.9 = 9折）

#### 有效期
- 設定報價單有效期（系統預設為當日起 30 天）

3. 點擊「**存檔**」

### 4.3 報價單狀態說明
| 狀態 | 說明 |
|------|------|
| 草稿 | 報價單剛建立，尚未正式提交 |
| 待回簽 | 已發送給客戶，等待客戶確認 |
| 已成立 | 客戶已確認，轉為正式訂單 |

### 4.4 測試案例
```
測試案例 3：建立報價單
1. 先建立客戶：CUST-TEST01
2. 先建立產品：P-TEST01
3. 新增報價單：
   - 客戶：CUST-TEST01
   - 品項：P-TEST01 x 10 個
   - 單價：1000
   - 折扣：無
   - 預期結果：報價單總額 = 10,000 元

測試案例 4：報價單折扣計算
- 數量：10 個
- 單價：1000 元
- 折扣率：0.9（9折）
- 預期結果：
  - 原價總額：10,000 元
  - 折扣後總額：9,000 元
```

## 五、銷售訂單管理 (Sales Order)

### 5.1 操作目的
將確認的報價單轉為正式銷售訂單，開始後續出貨與帳款流程。

### 5.2 操作步驟
1. 點擊右上角按鈕：「**轉銷售訂單**」
2. 彈出「新增銷售訂單」視窗

| 欄位名稱 | 說明 | 範例 |
|---------|------|------|
| 客戶名稱 | 選擇客戶 | 台北貿易股份有限公司 |
| 統一編號 | 帶入客戶資料 | 12345678 |
| 聯絡人 | 帶入客戶資料 | 王小明 |
| 產品與金額 | 選擇產品與數量 | 智慧手環 Pro x 50 |
| 付款條件 | T/T, L/C, 現金 | T/T 30 days |
| 貿易條件 | FOB, CIF, EXW | FOB |
| 預計交貨日 | 客戶要求交貨日 | 2026-04-15 |

3. 點擊「**存檔**」

### 5.3 訂單狀態說明
| 狀態 | 說明 |
|------|------|
| pending | 待出貨 |
| shipped | 已出貨 |
| paid | 已收款 |
| late | 逾期 |

### 5.4 測試案例
```
測試案例 5：建立銷售訂單
- 客戶：測試貿易有限公司
- 產品：測試商品 x 100 個
- 單價：1000 元
- 付款條件：T/T 30 days
- 貿易條件：FOB
- 預期結果：訂單建立成功，顯示於銷售訂單列表
```

## 九、帳款與帳齡分析

### 9.1 帳齡分析說明

| 帳齡區間 | 說明 | 顏色標示 |
|---------|------|---------|
| 未到期 (Current) | 尚在付款期限內 | 綠色 |
| 逾期 1-30 天 | 輕微逾期 | 黃色 |
| 逾期 31-60 天 | 中度逾期 | 橘色 |
| 逾期 61 天以上 | 嚴重逾期 | 紅色 |

### 9.2 測試案例
```

- 系統應顯示：
  - 未到期：$5,400,000 (65%)
  - 逾期 1-30 天：$1,200,000 (15%)
  - 逾期 31-60 天：$850,000 (10%)
```

## 十一、常見問題與排除

### Q1：客戶代號重複
**問題**：建立客戶時提示代號已存在
**解決**：請使用不同的客戶代號，或先搜尋確認是否已有此客戶

### Q2：報價單無法轉訂單
**問題**：報價單狀態為「草稿」無法轉訂單
**解決**：報價單需先「提交」確認後才能轉為正式訂單

### Q3：出貨單無法建立
**問題**：選不到銷售訂單
**解決**：確認該訂單狀態是否為「pending」，已出貨或已取消的訂單無法重複出貨

### Q4：發票金額與訂單不符
**問題**：發票金額與出貨單金額不一致
**解決**：檢查出貨單明細是否完整，發票金額應與出貨金額一致（含稅）
