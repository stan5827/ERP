## 表單操作通用原則

### 基本操作流程
1. **新增資料**：點擊「+ 新增」按鈕 → 填寫表單 → 點擊「確認」
2. **編輯資料**：點擊「編輯」圖標 → 修改表單 → 點擊「更新」
3. **查看詳情**：點擊「查看」圖標 → 瀏覽資訊 → 點擊「關閉」
4. **刪除資料**：點擊「刪除」圖標 → 確認刪除 → 系統處理

### 欄位操作指南
| 欄位類型 | 輸入方式 | 特殊說明 |
|----------|----------|----------|
| Text (文字) | 單行輸入框 | 可能有字元限制或格式要求 |
| Textarea (多行文字) | 多行輸入區域 | 適合較長的說明或備註 |
| Number (數字) | 數字輸入框 | 可能有最小/最大值限制 |
| Date (日期) | 日期選擇器 | 預設通常為今日或空值 |
| Select (下拉選單) | 下拉選單選擇 | 選項來自系統維護的基礎資料 |
| Checkbox (核取方塊) | 勾選框 | 是/否選項，預設通常未勾選 |
| 自動帶出 | 只讀顯示 | 根據其他欄位選擇自動填入的資訊 |
| 只讀欄位 | 無法修改 | 系統自動計算或維護的資料 |

### 必填與驗證
- **必填欄位**：欄位名稱後會顯示「*”符號，必須填寫才能提交
- **格式驗證**：如電子郵件、電話號碼、身分證字號等特殊格式
- **範圍驗證**：數值的最小值、最大值或允許範圍
- **邏輯驗證**：如結束日期必須大於開始日期
- **相依驗證**：填寫某個欄位時，其他相關欄位可能變為必填

### 常見狀態與操作
許多表單支援資料的生命週期管理：
- **草稿/待審核**：可編輯、修改、刪除
- **已核准/已發放**：通常只能查看，部分允許有限修改
- **已完成/已結案**：通常只能查看，不可修改
- **已取消/已退回**：取決於業務規則，可能允許重新提交

## 模組間關聯

ERP系統的各個模組透過以下關聯進行資料流通：

### 採購 → 庫存 → 生產 鏈
1. 採購訂單(PO) → 進貨 → 庫存增加(SKU庫存量)
2. 庫存領料 → 生產工單(WO) → 消耗原料庫存
3. 製品入庫 → 庫存增加(成品SKU庫存量)

### 銷售 → 生產 → 採購 鏈
1. 銷售訂單(SO) → 需要生產 → 建立生產工單(WO)
2. 生產工單(WO) → 需要原料 → 建立內部請購單(PR)
3. 內部請購單(PR) → 經核准 → 拋轉採購單(PO)

### 財務整合
- 固定資產折舊 → 費用攤提
- 庫存成本 → 銷售成本
- 人力資源薪資 → 人力費用
- 生產成本 → 產品成本

## 新手上手建議

### 第一週：熟悉基本操作
1. 從您常用的模組開始（如人力資源或庫存管理）
2. 練習查看現有資料，熟悉列表操作和篩選功能
3. 試著新增一些測試資料，熟悉表單填寫和驗證
4. 練習編輯和刪除測試資料（注意不要影響正式資料）

### 第二週：了解關鍵流程
1. 學習您職責相關的主要業務流程
2. 了解上游和下游模組如何影響您的工作
3. 練習跨模組的基本操作（如從請購單建立採購單）
4. 了解報表和查詢功能，學習如何獲取所需資訊

### 第三週：深入應用
1. 探索進階功能，如批量操作、自動化流程
2. 學習如何使用系統進行問題追蹤和根源分析
3. 參與系統優化建議，分享您的使用經驗
4. 開始協助新同事熟悉系統操作

## 注意事項

### 資料安全
- 請勿將帳號密碼透露給他人
- 完成操作後及時登出或鎖定螢幕
- 請按照公司資料安全政策操作系統

### 異常處理
- 遇到系統錯誤時，請記錄錯誤訊息並通報資訊部
- 不要自行嘗試修復可能導致資料損壞的操作
- 重要操作建議在非繁忙時段進行，以免影響其他用戶

### 資料備份
- 系統會自動進行定期備份
- 個人工作檔案請自行備份到指定位置
- 重要資料變更前建議先截圖或記錄原始值

## 常見問題 FAQ

**Q：為什麼我找不到某個選項？**
A：選項通常來自基礎資料表，可能需要先在對應的維護畫面新增該資料。

**Q：為什麼我無法編輯某筆資料？**
A：資料可能處於已核准、已完成或已鎖定狀態，僅限查看。

**Q：系統顯示「無權限」該怎麼辦？**
A：請確認您的帳號權限設定，需要時向主管申請或聯繫系統管理員。

**Q：如何匯出大量資料？**
A：大多數列表頁面都有匯出功能，支援Excel或CSV格式。

**Q：系統回應很慢該怎麼辦？**
A：請檢查您的網路連線，或嘗試重新整理頁面。持續問題請通報資訊部。
