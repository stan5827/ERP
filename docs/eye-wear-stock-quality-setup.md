# 眼鏡產品庫存與檢驗設定建議表

## 1. 建議的品號拆分

左右件建議拆成不同品號，讓工單、批號與檢驗報告可以追到實際零件。若公司採購或銷售以一對為單位，可用單位換算處理，不要把左右件合成同一個庫存品號。

| 品項 | 品號範例 | 品項類別 | 來源類型 | 追蹤方式 |
|---|---|---|---|---|
| 左鏡片 | `LS-LENS-L` | 半成品 | 自製 | 批次 |
| 右鏡片 | `LS-LENS-R` | 半成品 | 自製 | 批次 |
| 鏡架 | `LS-FRAME` | 半成品 | 自製 | 批次 |
| 左鏡腳 | `LS-TEMPLE-L` | 半成品 | 自製 | 批次 |
| 右鏡腳 | `LS-TEMPLE-R` | 半成品 | 自製 | 批次 |
| 眼鏡成品 | `FG-001` | 成品 | 自製 | 批次；依保固/序號追溯需求選擇性啟用序號 |
| 射出原料（如塑料粒） | 依材質編碼 | 原料 | 外購 | 批次 |

實際品號請依企業既有編碼規則調整；同一零件若材質、顏色、尺寸或模具不同，應建立不同 SKU 或明確的 SKU 規格。

## 2. 對照「庫存設定」分頁

以下欄位對應商品編輯畫面的「庫存設定」。左、右零件可套用相同原則，再依料號、規格和儲位分開管理。

| 畫面欄位 | 射出原料 | 鏡片/鏡架/鏡腳半成品 | 眼鏡成品 |
|---|---|---|---|
| 批次管理 | 啟用 | 啟用 | 啟用 |
| 序號管理 | 關閉 | 通常關閉 | 需要單品保固追溯時啟用，否則關閉 |
| 進料檢驗（IQC） | 啟用，來料檢驗後才收料 | 外購/委外品啟用；自製品以工序檢驗為主 | 自製成品通常關閉；外購成品啟用 |
| 出貨檢驗（OQC） | 關閉 | 僅會個別出貨的半成品才啟用 | 啟用 |
| 預設存放倉庫 | 原料倉 | 在製品倉 | 成品倉 |
| 預設存放儲位 | 原料待驗/合格區 | 對應零件的在製品區 | 成品待出貨或成品儲位 |

IQC/OQC 是品項庫存政策；自製過程中的檢驗應另外以「工序檢驗範本」定義，兩者不可互相取代。若系統不區分待驗與合格儲位，應先把 IQC 結果記錄完成，再由人員將物料移至合格儲位。

## 3. 工藝、檢驗範本與儲位規則

每一項工序連結一份適用於該 SKU（或共用於該工序）的檢驗範本。報工/完工時按範本記錄實測值、判定、檢驗人、時間、批號及抽樣數；範本版本應保留在檢驗報告快照中。

| 產品/工單 | 工藝順序 | 工序檢驗範本建議 | 完工後庫存去向 |
|---|---|---|---|
| 左鏡片 | 射出 → 防霧強化 | 射出：外觀、尺寸、翹曲；防霧強化：塗層外觀、附著/耐磨、透光或防霧效果 | 各工序完成先進在製品倉對應儲位 |
| 右鏡片 | 射出 → 防霧強化 | 同左鏡片；範本可共用，但報告仍須保留左右 SKU | 各工序完成先進在製品倉對應儲位 |
| 鏡架 | 射出 | 外觀、尺寸、缺料/毛邊、關鍵結構尺寸 | 在製品倉鏡架儲位 |
| 左鏡腳 | 射出 | 外觀、尺寸、鉸鏈/裝配位置 | 在製品倉左鏡腳儲位 |
| 右鏡腳 | 射出 | 同左鏡腳；保留左右 SKU 區別 | 在製品倉右鏡腳儲位 |
| 眼鏡成品 | 組裝 → 最終檢驗（OQC） | 組裝：左右件/螺絲/鉸鏈/開合；OQC：外觀、左右鏡片方向、配戴/功能、包裝與標籤 | 合格後進成品倉成品儲位，再依出貨單出庫 |

尺寸或性能項目應設定允收上下限、單位、檢驗方法、量具及抽樣計畫；外觀/功能項目可用合格/不合格或選項。對影響安全或法規的關鍵項目，標記為關鍵檢驗項目並按企業品質程序處理。

「預設存放倉庫/儲位」是 SKU 的預設收貨/存放位置，不代表每道工序會自動搬運庫存。工序完工後若需轉入下一個工序區或不同儲位，仍須依現有庫存移轉/入庫流程操作。

## 4. 出貨檢驗報告規則

1. 出貨明細應帶出成品 SKU、數量與批號；啟用批次管理時，應填寫實際出貨批號。
2. 系統依出貨單的銷售訂單、成品 SKU、對應工單及工藝順序彙整工序檢驗報告。
3. 每道預期工序須有啟用中的適用範本及該工單的檢驗紀錄；缺範本、缺紀錄或找不到工單時，報告列出警示。
4. 報告列出各檢驗項目規格、實測值、判定、檢驗人、檢驗時間、範本版本及批號，供列印/存檔追溯。
5. 判定不合格或資料不完整時，顯示「不合格」或「未完成」及警示，不由此報告端點阻擋出貨。出貨放行仍依公司核准的品質/出貨流程執行。
6. 若 OQC 必須納入這份出貨報告，將最終 OQC 建模為成品工藝路線的末道工序，設定其檢驗範本並建立檢驗報告；只勾選 SKU 的 OQC 欄位本身不會產生實測值或報告項目。

目前出貨檢驗報告 API 為 `GET /api/erp/delivery-orders/{id}/inspection-report`。報告以銷售訂單及 SKU 對應工單追溯檢驗；若出貨行未填批號，會彙整該訂單同 SKU 工單紀錄並提示批號缺漏。因此建議正式出貨流程必填批號。

## 5. 建議設定順序

1. 建立倉庫與儲位：原料倉、在製品倉、成品倉，以及待驗/合格/待出貨等實際儲位。
2. 建立 SKU：拆分左右件，設定基本單位、來源類型、批次/序號、IQC/OQC 與預設倉庫/儲位。
3. 建立工序與工作中心：射出、防霧強化、組裝、最終檢驗，並分配實際工作中心。
4. 建立產品 BOM 與工藝路線：鏡片路線包含射出及防霧強化；鏡架、左右鏡腳包含射出；眼鏡成品包含組裝與最終檢驗。
5. 為每道需檢驗的工序建立範本，並按工單/批號留下每次檢驗紀錄。
6. 建立出貨單時指定批號，查看出貨檢驗報告；確認檢驗紀錄、缺漏警示及 OQC 結果後列印/存檔。
