# MPS 粗略產能規劃 (RCCP) 與多幣別管理手冊

本文件旨在說明主生產規劃 (MPS) 模組中，產能校準與匯率管理的維護責任與系統機制，以確保規劃結果的準確性。

---

## 一、粗略產能規劃 (RCCP) 資料維護

資料校準與維護責任分工如下：

### 1. 關鍵資源可用產能維護
*   **負責人**：生產管理人員 (Production Planner)。
*   **維護內容**：負責維護 `RccpResource` 主檔中各資源之「每時格可用產能」。
*   **維護說明**：
    *   每時格可用產能的定義例如：以週為 MPS 時格時，標準值可設為每週 40 小時（單一產線或人力池），再視實際加班政策及設備稼動率調整。
    *   若有多班制、季節性調整或設備保養計畫，亦應在 `RccpResource` 中反映於不同時格或以效率係數修正。

### 2. 品項對資源用量維護
*   **負責人**：製程工程 / 生產技術或生產管理人員。
*   **維護內容**：在品項主檔中設定該品項對應的關鍵資源與標準資源用量。
*   **維護說明**：
    *   標準資源用量透過 `RccpItemResource`（或品項主檔中的 RCCP 區段）維護，例如：每生產 1 件成品需佔用產線 A 0.05 小時，或產線 A 每小時可生產 20 件。
    *   若製程或節拍有變更，須同步更新資源用量資料，以確保 RCCP 試算結果反映最新實際能力。

> [!NOTE]
> 以上兩類資料為粗略產能規劃 (RCCP) 的校準基礎。系統將依據 MPS 的各時格計畫量，結合 `RccpResource` 的可用產能與品項對資源的標準用量，計算各關鍵資源在每一時格的負荷率，並於 MPS 介面提供視覺化示警與超載提示。

## 二、匯率同步機制與策略

### 1. 匯率資料模型
*   系統以 `ExchangeRate` 模型儲存匯率資訊，包含：
    *   `FromCurrency`、`ToCurrency` (來源與目標幣別)。
    *   `Rate` (匯率值)。
    *   `ValidFrom` / `ValidTo` (生效期間)。
    *   `RateType` (匯率類型，如：SPOT 即期、BUDGET 預算、AVERAGE 平均)。
    *   `Source` (來源標記，如：MANUAL 手動、ECB、CENTRAL_BANK)。
*   所有多幣別金額換算（例如 MPS 產值估算、跨幣別報表）均以此為唯一來源。

### 2. 匯率維護方式
*   **初期階段**：可由財務人員透過後台畫面手動維護每日或每期匯率，並可設定預設報表用匯率（如每月預算匯率）。
*   **歷史追蹤**：系統保留匯率版本與生效期間，避免歷史資料因匯率更新而重算錯誤。

### 3. 外部匯率 API 對接 (未來擴充)
*   未來可進一步對接外部匯率服務（例如銀行或金融資訊提供者 API），由排程程式 (Scheduled Job) 自動抓取最新匯率。
*   **自動化邏輯**：
    *   **指定來源**：例如 ECB、指定銀行。
    *   **支援幣別**：TWD、USD、EUR 等。
    *   **更新頻率**：設定每日定時更新（如 16:00），若 API 失敗則保留前一有效匯率並發出系統通知。
    *   **稽核追蹤**：所有自動更新皆記錄來源、抓取時間與原始 API 回應。

### 4. 安全與權限管理
*   僅授權之 **財務 / 系統管理角色** 可調整匯率來源設定與啟用/停用自動同步功能。
*   一旦匯率已被使用於結帳或已發佈報表，系統將限制修改或需經核准審批流程。
