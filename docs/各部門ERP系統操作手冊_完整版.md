# Nexus ERP 供應商協作平台完整操作手冊

## 系統概述

Nexus ERP 供應商協作平台 (Supplier Portal) 是一個專為製造產業設計的外部供應商入口網站，實現企業與供應商之間的無縫數位化協作。本系統涵蓋七大核心模組，包括詢報價管理、採購訂單、交貨出貨單、發票帳款、品質客訴、供應商績效及公司資料合約管理。

---

## 一、供應商入口網站 (Supplier Portal)

供應商透過專屬帳號登入系統，可進行報價、訂單確認、交貨管理與帳務查詢。

### 1.1 登入與首頁

**操作路徑**：http://localhost:5174/supplier

**功能說明**：
- 顯示待處理事項摘要（待確認訂單、待回覆詢價、本月預計收款）
- 供應商評分與等級顯示
- 企業公告訊息
- 快速導航捷徑

**待辦事項類型**：
| 類型 | 說明 | 數量範例 |
|------|------|----------|
| 待確認新訂單 (PO) | 需確認接單或請求變更 | 5 筆急件 |
| 待回覆詢價 (RFQ) | 今日到期需回覆 | 2 件 |
| 待處理品質客訴 | 8D 報告回覆 | 1 件 |

### 1.2 詢報價管理 (RFQ)

**功能**：
- 檢視企業發佈的詢價單與規格附件
- 線上回報單價、交期與最小訂購量 (MOQ)
- 上傳報價單附件

**操作流程**：
1. 點擊左側「詢報價管理 (RFQ)」頁籤
2. 檢視待回覆詢價清單
3. 點擊任一詢價單查看詳情
4. 填寫報價資訊（單價、交期、條件）
5. 提交報價

**欄位說明**：
- `RFQ 單號`：系統自動編號（格式：RFQ-YYYY-XXX）
- `詢價日期`：企業發出日期
- `報價截止日`：回覆期限
- `狀態`：待報價、報價中、已回覆、已決標

### 1.3 採購訂單 (PO)

**功能**：
- 接收最新 PO 通知
- 線上點選「確認接單」或「拒絕/請求修改」
- 維護交貨排程

**操作流程**：
1. 點擊「採購訂單 (PO)」頁籤
2. 檢視所有採購訂單
3. 選擇訂單進行確認或變更
4. 填寫承諾交期與備註
5. 提交確認

**訂單狀態**：
| 狀態 | 說明 |
|------|------|
| pending | 待確認 |
| acknowledged | 已確認接單 |
| rejected | 已拒絕 |
| needs_revision | 需修改 |
| partial_shipped | 已部分出貨 |
| completed | 已完交 |
| cancelled | 已取消 |

### 1.4 交貨與出貨單 (ASN)

**功能**：
- 線上建立出貨通知 (ASN)
- 輸入批號 (Lot Number)、製造日期、效期
- 追蹤收貨狀態

**操作流程**：
1. 點擊「交貨與出貨單 (ASN)」頁籤
2. 點擊「新增出貨通知」
3. 選擇關聯的採購訂單
4. 填寫出貨資訊（日期、數量、物流商）
5. 輸入批號與效期資料
6. 提交出貨單

**ASN 狀態**：
| 狀態 | 說明 |
|------|------|
| pending | 待出貨 |
| shipped | 已出貨 |
| in_transit | 運輸中 |
| delivered | 已送達 |
| received | 已收貨確認 |

### 1.5 發票與帳款 (AP)

**功能**：
- 線上開立請款單
- 關聯 PO/收貨單 (GR) 達成三方勾稽
- 追蹤發票審核狀態
- 查看付款進度與帳齡

**操作流程**：
1. 點擊「發票與帳款 (AP)」頁籤
2. 選擇「開立發票」
3. 關聯對應的 PO 與收貨單
4. 輸入發票號碼與金額
5. 提交請款

**帳款狀態**：
| 狀態 | 說明 |
|------|------|
| 待付款 | 等待企業付款 |
| 折扣期內 | 適用早付折扣 |
| 已結清 | 款項已付清 |
| 逾期 | 超過付款期限 |

### 1.6 品質客訴 (8D/CAPA)

**功能**：
- 檢視品質異常客訴單
- 線上回覆 8D 報告
- 上傳改善照片與報告
- 追蹤結案狀態

**8D 報告流程**：
1. **D1 成立團隊**：指定改善負責人
2. **D2 問題描述**：說明異常情況
3. **D3 臨時對策**：立即隔離與篩選
4. **D4 根本原因分析**：使用 5Why/魚骨圖
5. **D5 長期對策**：防止再發
6. **D6 對策驗證**：確認有效性
7. **D7 預防措施**：標準化
8. **D8 結案**：完成與關閉

**客訴狀態**：
| 狀態 | 說明 |
|------|------|
| open | 新建客訴 |
| in_progress | 處理中 |
| pending_response | 等待供應商回覆 |
| resolved | 已解決 |
| closed | 已結案 |

### 1.7 供應商績效看板

**功能**：
- 檢視企業評分記錄 (KPI)
- 查看 OTIF 準時交付率
- 品質缺陷率 (PPM) 趨勢
- 訂單準確率

**KPI 指標說明**：
| 指標 | 目標值 | 計算方式 |
|------|--------|----------|
| OTIF (準時完整交付率) | ≥95% | 準時件數 / 總交付件數 |
| PPM (品質缺陷率) | ≤50 PPM | 缺陷數 / 總交貨數 × 1,000,000 |
| 訂單準確率 | ≥98% | 正確訂單數 / 總訂單數 |
| 變更回應時間 | ≤24 小時 | 平均回應小時數 |

**評級標準**：
| 評級 | 分數範圍 | 說明 |
|------|----------|------|
| A | 90-100 | 優質供應商 |
| B | 80-89 | 良好供應商 |
| C | 70-79 | 合格供應商 |
| D | 60-69 | 需改進 |
| F | <60 | 不合格 |

### 1.8 公司資料與合約

**功能**：
- 維護公司基本資料
- 更新聯絡人資訊
- 上傳證照與認證文件
- 管理銀行帳戶
- 下載企業合約與規範

**文件類型**：
- ISO 證書 (ISO9001, IATF16949, ISO14001)
- RoHS/REACH 檢測報告
- 營業執照
- 稅籍資料
- 保單
- 保密協議 (NDA)

## 二、採購人員操作手冊

**主要職責**：管理供應商、處理請購、執行詢比議價、管理採購訂單。

### 2.1 請購單 (PR) 管理

**操作路徑**：採購付款 > 請購單列表

**功能**：
- 檢視各部門提出的請購需求
- 審核請購單並啟動詢價

**請購單狀態**：
| 狀態 | 說明 |
|------|------|
| pending | 待處理 |
| rfq | 詢價中 |
| approved | 已核准 |
| rejected | 已駁回 |

### 2.2 詢比議價 (RFQ)

**操作路徑**：採購付款 > 詢比議價

**功能**：
- 向多家供應商發出詢價
- 收集並比較報價
- 系統自動標示最低價與最短交期

**決標流程**：
1. 選擇議價中的 RFQ
2. 比較供應商報價
3. 選擇最佳供應商
4. 系統自動產生 PO

### 2.3 採購訂單 (PO) 管理

**操作路徑**：採購付款 > 採購訂單

**功能**：
- 建立與維護採購訂單
- 追蹤供應商回覆狀態
- 管理一攬子訂單 (Blanket Order)
- 處理訂單變更

**一攬子訂單**：
- 適用於長期供應協議
- 可設定分批交貨排程
- 最低/最高訂購量限制

### 2.4 進貨點收 (GR)

**操作路徑**：採購付款 > 進貨點收

**功能**：
- 錄入供應商到貨數量
- 執行 IQC 品質檢驗
- 產生品質判定結果

**品質判定**：
| 結果 | 說明 |
|------|------|
| 合格 | 允收入庫 |
| 特採 | 特殊原因允收 |
| 退貨 | 不合格退還供應商 |

## 三、財務人員操作手冊

**主要職責**：應付帳款管理、發票勾稽、付款處理。

### 3.1 應付帳款 (AP) 管理

**操作路徑**：採購付款 > AP 應付帳款

**功能**：
- 檢視所有應付款項
- 追蹤發票勾稽狀態
- 管理早付折扣

### 3.2 三方勾稽 (Three-Way Matching)

**功能**：自動比對「PO 訂單」、「GR 實收」、「供應商發票」金額

**勾稽結果**：
| 結果 | 說明 |
|------|------|
| Match | 三方金額相符，可付款 |
| Variance | 金額不符，需人工覆核 |
| Blocked | 異常，凍結付款 |

### 3.3 付款處理

**操作路徑**：採購付款 > 付款匯款

**功能**：
- 產生付款批次
- 產生銀行匯款媒體檔
- 記錄匯款資訊

### 3.4 早付折扣管理

**功能**：
- 設定折扣條件 (如 2/10 net 30)
- 追蹤折扣到期日
- 計算折扣金額

## 四、品質管理人員操作手冊

**主要職責**：處理品質客訴、管理 8D 報告、執行 CAPA。

### 4.1 品質客訴建立

**操作路徑**：採購付款 > 品質客訴 > 新建客訴

**欄位說明**：
- `客訴單號`：QC-8D-YYYY-XXX
- `優先級`：High / Medium / Low
- `關聯 PO`：受影響的採購訂單
- `批號`：受影響物料批號
- `數量`：受影響數量
- `缺陷類型`：外觀不良、功能異常、尺寸偏差等
- `PPM`：缺陷率

### 4.2 8D 報告管理

**功能**：
- 建立 8D 報告
- 追蹤供應商回覆
- 審核改善措施

### 4.3 CAPA 管理

**操作路徑**：採購付款 > 品質客訴 > CAPA

**功能**：
- 建立糾正措施 (Corrective Action)
- 建立預防措施 (Preventive Action)
- 追蹤改善進度

**CAPA 狀態**：
| 狀態 | 說明 |
|------|------|
| open | 待處理 |
| in_progress | 執行中 |
| verified | 已驗證 |
| closed | 已結案 |

### 4.4 不合格報告 (NCR)

**功能**：
- 記錄品質異常
- 決定處置方式
- 追蹤成本影響

**處置方式**：
| 方式 | 說明 |
|------|------|
| Use as is | 使用現狀 |
| Rework | 重工 |
| Return | 退貨 |
| Scrap | 報廢 |
